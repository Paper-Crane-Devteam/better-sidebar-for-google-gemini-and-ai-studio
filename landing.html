Questions & Answers

Can I try Power Pack before buying?
Yes. Install Better Sidebar and a 3-day Power Pack trial starts the first time you open it. No payment method, no code. Remaining time shows in the extension popup and Settings. When it ends, you're back on the free plan and everything you created stays on your device.
Does the free version stay free?
Yes. Folders, tags, search, outline, prompts, snippets, Gems and notebooks, Drive sync, Markdown/JSON export, and the read-only agents stay free. Workspace Agent is usable on the free plan too, with 1 workspace and 5 files. Power Pack lets the agents make changes, removes the workspace limits, and adds the Web Agent and Obsidian/Notion export.
How do I activate after purchase?
You'll receive a license key instantly. If you haven't yet, install the extension. Then open Better Sidebar → Settings → Packs → paste your key → click Activate. Takes 10 seconds.
What if I hit the activation limit?
One licence is 10 activations (browser profiles, not Better Sidebar's own multi-account profiles). Release a slot from Settings → Packs before you wipe a machine, then activate the new one. Same token.
What can each agent do?
BetterSidebar Agent: query and (with Power Pack) change conversations, folders, tags, prompts, and snippets. Workspace Agent: create and edit text/code; read and precisely edit Word (tracked changes, comments), Excel (formulas, new sheets), PDF (highlights, sticky notes, page ops), and PowerPoint. Browser Agent: dedupe and group tabs, tidy bookmark folders, with rollback. Web Agent: fill forms, click through steps, and collect data on a page you hand it. Each one only works in its own area.
Which browsers and sites does it work on?
Better Sidebar runs on Gemini and Google AI Studio, in Chrome and Firefox. One licence covers both sites. Workspace files persist across platforms, so a file written from Gemini opens in AI Studio. The Web Agent is Chrome only for now and needs the free Web Agent Connector.
Is my data safe?
Your folders, tags, notes, and prompts live in a local SQLite database in your browser. Better Sidebar has no server that sees your chats or files. The only request we handle is the licence check. The agents run through your existing Gemini or AI Studio session, so what reaches Google is the same as any message you type: the prompt, plus whatever the agent read to answer you. For the Web Agent that includes the page's visible text and form structure, but never password fields.
Do I have to upload a file first?
For text and code, no. Ask it to build the files. Word, Excel, PDF, and PowerPoint have to be dragged in: a browser extension can't open those from disk on request, and generating brand-new binary files from scratch isn't supported yet.
Why buy during beta?
Workspace Agent is in beta: it works, it's careful with files, and you'll find rough edges. Bug reports get fast fixes. The current Power Pack price is the beta price, and it goes up once Workspace Agent is out of beta. 7-day no-questions refund if it isn't useful.
Does it use my API keys or tokens?
No. All agents use your existing Gemini or AI Studio session. No API keys, no extra tokens, no Better Sidebar server. The model you're already talking to is the one doing the work.

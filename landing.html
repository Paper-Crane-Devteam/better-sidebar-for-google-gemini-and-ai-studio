Questions & Answers

Does the free version stay free?
Yes. Folders, tags, search, prompts, Drive sync, Markdown/JSON export, and the read-only agent stay free. Workspace Agent is usable on the free plan too — 1 workspace, 5 files. Power Pack is unlimited files, agent writes, and Obsidian/Notion.
How do I activate after purchase?
You'll receive a license key instantly. Open Better Sidebar → Settings → Packs → paste your key → click Activate. Takes 10 seconds.
What if I hit the activation limit?
One licence is 10 activations (browser profiles, not Better Sidebar's own multi-account profiles). Release a slot from Settings → Packs before you wipe a machine, then activate the new one. Same token.
Is my data safe?
The agent runs through your existing Gemini or AI Studio session. Queries hit a local SQLite database in the browser. Better Sidebar has no server that sees your chats or workspace files. What reaches Google is the same as any message you type: the prompt, including whatever the agent read in order to answer you.
Does this work on AI Studio too?
Yes. Both agents work on Gemini and AI Studio. Workspace files persist across platforms — a file written from Gemini is readable from AI Studio.
What can the agents actually do?
Better Sidebar agent — query and (with Power Pack) change conversations, folders, tags, prompts, snippets. Workspace agent — create and edit text/code from scratch; read and precisely edit existing Word (tracked changes, comments), Excel (formulas, new sheets), PDF (highlights, sticky notes, page ops), and PowerPoint. They cannot see each other's data. That split is the point.
Do I have to upload a file first?
For text and code, no. Ask it to build the files. Word, Excel, PDF, and PowerPoint have to be dragged in — a browser extension can't open those from disk on request, and generating brand-new binary files from scratch isn't supported yet.
Why buy during beta?
Workspace Agent is in beta: it works, it's careful with files, and you'll find rough edges. Bug reports get fast fixes. The current Power Pack price is the beta price — it goes up once the feature is out of beta. 7-day no-questions refund if it isn't useful.
Does it use my API keys or tokens?
No. Both agents use your existing Gemini or AI Studio session — no API keys, no extra tokens, no Better Sidebar server. The model you're already talking to is the one doing the work.

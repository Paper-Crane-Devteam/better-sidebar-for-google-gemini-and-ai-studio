## 🔥 重磅新功能详解

### 1. 🔄 后台静默消息同步：把“真正的全文搜索”还给你

- **痛点告别**：以往插件只有在你“亲自点开”某个对话时，才会提取其中的消息建立索引。如果你在多台设备间切换，很多没打开过的会话就搜不到正文，用起来总感觉搜索“漏风”。
- **静默后台补全**：现在插件支持在后台静默拉取历史消息并补全本地索引，彻底解决跨设备搜不到消息的问题。
- **平缓节流与安全**：为了防止请求频率过高触发 Google 的接口限制（Rate Limit），该功能**默认是关闭的**，需要你手动在设置中开启；开启后也会以平缓的节流节奏在后台慢慢更新，绝不给账号带来风控负担。
- **状态总览一清二楚**：我们专门设计了一个同步管理弹窗，哪些会话已同步、哪些尚未同步一目了然。对于某些你着急想立刻检索的对话，也可以在面板里直接手动触发单条同步。

### 2. ⌨️ Cmd+K Command Palette：Raycast 风格全键盘流面板

全量消息索引就绪后，快捷指令面板才算真正拥有了灵魂！
- **随时唤出**：无论你在哪个页面，只要按下 **`Cmd + K`**（Windows 上为 **`Ctrl + K`**），即可呼出居中全局面板。
- **聚合多维搜索**：
  - 搜索历史会话标题与描述；
  - 直接全文匹配聊天正文；
  - 搜索插件功能与快速动作跳转。
- **全键盘操作**：方向键上下切换、回车立即跳转或执行，专为追求极致效率的 Power Users 打造。

### 3. 🧩 左侧导航图标栏（Icon Bar）高度自定义与拖拽排序

随着 Better Sidebar 功能日益丰富，我们也收到不少轻量用户的反馈：“有些功能我平时很少用到，全部堆在左边有点增加认知负担”。
- **按需显隐**：现在你可以在设置中自由勾选保留哪些功能图标，不常用的直接隐藏，界面瞬间清爽。
- **自由拖拽排序**：你可以随心拖动图标调整上下次序，把你最顺手、最常用的功能排在第一位，定制属于你自己的轻量工作台。

### 4. 🤖 Browser Agent：让 AI 成为你的浏览器管家（实验性）

我们在想：既然 AI 能够帮我们管理插件数据和编写代码，为什么不能帮我们把日常混乱的浏览器好好整理一番呢？
作为一个日常标签页“只开不关”的重度用户，经常不知不觉堆积了几十个 Tab，密密麻麻连网页标题都看不见；收藏夹更是攒了几年，到处是重复的文件夹和死链。
Browser Agent 正是为此而生：
- **标签页智能净化**：自动识别去重（同一网页只保留一份），并根据页面主题智能创建标签分组，瞬间告别混乱。
- **收藏夹深度大扫除**：梳理多年堆积的书签，自动分门别类，合并重复文件夹，清理失效网站。
- **版本快照与一键回退**：**数据安全永远是第一位的！** AI 每次执行整理前，都会自动保存当前状态的备份快照。修改前和修改后的样子都会妥善留存，如果对整理结果不满意，随时可以**一键回退到之前的状态**，零误改误删风险。（*注：如果对浏览器数据极度谨慎，也推荐在 Chrome 书签管理器中提前手动导出一份 html 备份，双重保障更安心。*）

### 5. 🎨 BetterSidebar Agent 实时主题定制：告别繁琐，一句话换装

过去想做一个个性化主题，流程非常繁琐：把提示词贴到外部模型 -> 等待生成 JSON -> 手动复制回设置里导入。
- 现在只需在对话中直接告诉 BetterSidebar Agent 你的想法：
  > *“帮我设计一个黑客帝国风格的暗黑荧光绿主题”* 或 *“来一个柔和低饱和度的日系奶茶色”*
- Agent 会自动生成专属配色并**直接应用（Apply）立即生效**！
- 觉得某个背景色太亮或者输入框对比度不够？直接继续对它说：*“把背景调暗一点，边框亮一点”*，Agent 会实时修改更新。现在每天都可以换一个符合当下心情的专属皮肤了！

## 🔥 Подробный обзор новинок

### 1. 🔄 Тихая фоновая синхронизация сообщений: настоящий полнотекстовый поиск

- **Прежняя проблема**: Раньше расширение индексировало сообщения только тогда, когда вы физически открывали конкретный диалог. При работе на разных устройствах поиск часто выдавал пустоту по тем чатам, которые ещё не открывались локально.
- **Тихое индексирование в фоне**: Теперь Better Sidebar умеет незаметно подгружать историю сообщений в фоновом режиме, дополняя локальный поисковый индекс.
- **Защита от лимитов (Rate Limit)**: Чтобы не перегружать запросы к API Google, эта функция **по умолчанию отключена**. Вы можете включить её в настройках, где она будет работать в плавном, безопасном для аккаунта темпе.
- **Наглядный статус синхронизации**: Мы добавили специальное окно управления, где четко видно, какие чаты синхронизированы, а какие еще ожидают. Если какой-то диалог нужен в поиске прямо сейчас, его можно синхронизировать вручную одним кликом.

### 2. ⌨️ Cmd+K Command Palette: Управление целиком с клавиатуры

Когда все сообщения проиндексированы, палитра команд раскрывается на полную мощность:
- **Мгновенный вызов**: Нажмите **`Cmd + K`** (или **`Ctrl + K`** в Windows) в любом месте, чтобы открыть панель по центру экрана.
- **Единый мультипоиск**:
  - Поиск по заголовкам и описаниям диалогов;
  - Прямой поиск по всему тексту сообщений;
  - Поиск и запуск функций расширения.
- **Никакой мыши**: Стрелки для навигации, Enter для перехода или выполнения действия. Настоящий подарок для любителей быстрой работы на клавиатуре.

### 3. 🧩 Полная кастомизация левой панели иконок

С ростом числа инструментов Better Sidebar мы получили отзывы от пользователей, предпочитающих минимализм: «Я пользуюсь не всеми вкладками каждый день, и лишние значки создают визуальный шум».
- **Скрытие лишнего**: Теперь в настройках можно выбрать, какие именно иконки должны отображаться на левой панели.
- **Сортировка перетаскиванием (Drag-and-Drop)**: Меняйте значки местами, чтобы самые нужные функции были всегда под рукой.

### 4. 🤖 Browser Agent: ИИ на страже порядка в браузере (Экспериментально)

Мы подумали: если ИИ уже умеет работать с файлами и кодом, почему бы не поручить ему наведение порядка в браузере?
Если вы привыкли открывать десятки вкладок, пока заголовки не сожмутся в точку, а в закладках годами копятся дубликаты и мертвые ссылки, Browser Agent спешит на помощь:
- **Порядок во вкладках**: Автоматически находит и закрывает дублирующиеся вкладки (оставляя по одной для каждого адреса) и объединяет связанные страницы в тематические группы.
- **Уборка в закладках**: Структурирует запущенные папки, объединяет дубли и помогает избавиться от неработающих ссылок.
- **Снимки состояния и откат в один клик**: **Безопасность данных — абсолютный приоритет.** Перед внесением любых изменений агент автоматически сохраняет снимок текущего состояния. Если результат вам не понравится, вы можете **вернуться к предыдущему состоянию в один клик**. (*Совет: для полного спокойствия вы также можете предварительно экспортировать HTML-файл с закладками через стандартный диспетчер Chrome.*)

### 5. 🎨 Создание тем в реальном времени с BetterSidebar Agent

Раньше создание своей темы требовало рутины: копировать промпт -> генерировать JSON в другой нейросети -> копировать код обратно в настройки.
- Теперь достаточно просто описать идею в чате с BetterSidebar Agent:
  > *«Создай тему в стиле "Матрицы" с глубоким черным фоном и неоново-зелеными акцентами»* или *«Сделай мягкую палитру в оттенках японского молочного чая»*
- Агент сам сгенерирует палитру и **мгновенно применит тему**!
- Хотите что-то подправить? Просто напишите: *«Сделай фон чуть темнее, а границу поля ввода контрастнее»*. Тема обновится на лету. Меняйте оформление под настроение хоть каждый день!

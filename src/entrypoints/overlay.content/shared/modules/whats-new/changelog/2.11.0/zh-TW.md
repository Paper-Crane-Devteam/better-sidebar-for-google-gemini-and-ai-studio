## 🔥 重磅新功能詳解

### 1. 🔄 背景無感訊息同步：把「真正的全文搜尋」還給你

- **痛點告別**：以往擴充套件只有在你「親自點開」某個對話時，才會提取其中的訊息建立索引。如果你在多台裝置間切換，很多沒打開過的會話就搜不到內文，用起來總感覺搜尋「漏風」。
- **無感背景補全**：現在擴充套件支援在背景默默抓取歷史訊息並補齊本機索引，徹底解決跨裝置找不到訊息的問題。
- **平緩節流與安全**：為了防止請求頻率過高觸發 Google 的 API 頻率限制（Rate Limit），該功能**預設是關閉的**，需要你手動在設定中開啟；開啟後也會以平緩的節流節奏在背景慢慢更新，絕不給帳號帶來風控負擔。
- **狀態總覽一清二楚**：我們專門設計了一個同步管理彈窗，哪些對話已同步、哪些尚未同步一目了然。對於某些你著急想立刻檢索的對話，也可以在面板裡直接手動觸發單筆同步。

### 2. ⌨️ Cmd+K Command Palette：Raycast 風格全鍵盤流面板

全量訊息索引就緒後，快捷指令面板才算真正擁有了靈魂！
- **隨時喚出**：無論你在哪個頁面，只要按下 **`Cmd + K`**（Windows 上為 **`Ctrl + K`**），即可呼出置中全域面板。
- **聚合多維搜尋**：
  - 搜尋歷史對話標題與描述；
  - 直接全文比對聊天內文；
  - 搜尋擴充套件功能與快速動作跳轉。
- **全鍵盤操作**：方向鍵上下切換、Enter 立即跳轉或執行，專為追求極致效率的 Power Users 打造。

### 3. 🧩 左側導覽圖示欄（Icon Bar）高度自訂與拖曳排序

隨著 Better Sidebar 功能日益豐富，我們也收到不少輕量用戶的意見回饋：「有些功能我平時很少用到，全部堆在左邊有點增加認知負擔」。
- **按需顯隱**：現在你可以在設定中自由勾選保留哪些功能圖示，不常用的直接隱藏，介面瞬間清爽。
- **自由拖曳排序**：你可以隨心拖動圖示調整上下順序，把你最順手、最常用的功能排在第一位，打造屬於你自己的輕量工作台。

### 4. 🤖 Browser Agent：讓 AI 成為你的瀏覽器管家（實驗性）

我們在想：既然 AI 能夠幫我們管理擴充套件資料和編寫程式碼，為什麼不能幫我們把日常混亂的瀏覽器好好整理一番呢？
作為一個日常分頁「只開不關」的重度使用者，經常不知不覺堆積了幾十個 Tab，密密麻麻連網頁標題都看不見；書籤欄更是攢了幾年，到處是重複的資料夾和失效連結。
Browser Agent 正是為此而生：
- **分頁智慧淨化**：自動識別去重（同一網頁只保留一份），並根據頁面主題智慧建立分頁群組，瞬間告別混亂。
- **書籤深度大掃除**：梳理多年堆積的書籤，自動分門別類，合併重複資料夾，清理失效網站。
- **版本快照與一鍵還原**：**資料安全永遠是第一位的！** AI 每次執行整理前，都會自動儲存當前狀態的備份快照。修改前和修改後的樣子都會妥善留存，如果對整理結果不滿意，隨時可以**一鍵還原到之前的狀態**，零誤改誤刪風險。（*注：如果對瀏覽器資料極度謹慎，也推薦在 Chrome 書籤管理員中提前手動匯出一份 html 備份，雙重保障更安心。*）

### 5. 🎨 BetterSidebar Agent 即時主題自訂：告別繁瑣，一句話換裝

過去想做一個個性化主題，流程非常繁瑣：把提示詞貼到外部模型 -> 等待產生 JSON -> 手動複製回設定裡匯入。
- 現在只需在對話中直接告訴 BetterSidebar Agent 你的想法：
  > *「幫我設計一個駭客任務風格的暗黑螢光綠主題」* 或 *「來一個柔和低飽和度的日系奶茶色」*
- Agent 會自動產生專屬配色並**直接套用（Apply）立即生效**！
- 覺得某個背景色太亮或者輸入框對比度不夠？直接繼續對它說：*「把背景調暗一點，邊框亮一點」*，Agent 會即時修改更新。現在每天都可以換一個符合當下心情的專屬外觀了！

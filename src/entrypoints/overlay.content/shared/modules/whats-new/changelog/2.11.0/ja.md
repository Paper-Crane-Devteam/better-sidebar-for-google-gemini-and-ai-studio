## 🔥 新機能の詳しい紹介

### 1. 🔄 バックグラウンドメッセージ同期：本当の「全文検索」が復活

- **これまでの悩み**：以前は、ユーザーが実際にその会話を開いたタイミングでしかメッセージを読み込んでインデックス化していませんでした。そのため、複数デバイスを使っていると、一度も開いていない過去のチャットが検索にヒットしないという問題がありました。
- **サイレント同期で自動補完**：バックグラウンドで過去のメッセージを静かに読み込み、ローカルインデックスを自動補完。見つからない検索のストレスを完全に解消します。
- **レートリミット対策と安全性**：GoogleのAPI制限（Rate Limit）への抵触を防ぐため、この機能は**デフォルトでオフ**になっています。設定から手動でオンにでき、オンにした場合も安全なペースでゆっくり同期されます。
- **同期ステータスが一目でわかる**：どのチャットが同期済みで、どれが未同期かを一覧できる管理モーダルを用意しました。急いで検索対象に含めたい会話は、手動で個別に即時同期することも可能です。

### 2. ⌨️ Cmd+K Command Palette：Raycastスタイルのキーボード操作

メッセージの全文インデックスが揃ったことで、コマンドパレットが真の真価を発揮します！
- **どこからでも起動**：どの画面にいても、**`Cmd + K`**（Windowsは **`Ctrl + K`**）を押すだけで中央にパレットが呼び出せます。
- **統合マルチ検索**：
  - 会話のタイトルや説明文の検索
  - メッセージ本文の直接全文一致検索
  - プラグイン機能やショートカット操作の実行
- **マウス不要の快適さ**：矢印キーで選択してEnterキーで即ジャンプ。キーボード派のパワーユーザーに最高の体験をお届けします。

### 3. 🧩 左側アイコンバー（Icon Bar）の表示設定と並び替え

機能が増えるにつれて、ライトユーザーの方から「普段使わない機能も並んでいて画面が少しごちゃつく」という声をいただいていました。
- **表示/非表示の切り替え**：設定から必要な機能アイコンだけを選んで表示できるようになりました。不要なものは非表示にしてスッキリ作業できます。
- **ドラッグ＆ドロップで並び替え**：アイコンをドラッグして上下の順番を自由に入れ替えられます。よく使うツールを手が届きやすい場所に配置してください。

### 4. 🤖 Browser Agent：AIがあなたのブラウザ整理係に（実験的機能）

AIがプラグインデータの操作やコード生成ができるなら、散らかったブラウザの整理も任せられるはず！
気付けば何十個もタブを開きっぱなしにしてタイトルすら読めなくなったり、何年も前の重複ブックマークやリンク切れが放置されていたりしませんか？
Browser Agent はそんな悩みを一発で解決します：
- **タブの自動整理**：重複タブを自動排除（同じURLは1つだけ保持）し、トピックごとにスマートなタブグループを作成。
- **ブックマークの大掃除**：乱雑になったブックマークをカテゴリー別に整理し、重複フォルダの統合やリンク切れの整理をサポート。
- **スナップショットとワンクリック復元**：**データの安全性は何よりも最優先です。** AIが整理を行う前に、現在のブラウザ状態のスナップショットを自動保存します。変更前後の状態がしっかり記録されているため、結果が気に入らなければ**ワンクリックで以前の状態に復元**できます。（*※万全を期したい方は、念のためChromeのブックマークマネージャから手動でHTMLバックアップを書き出しておくこともおすすめです。*）

### 5. 🎨 BetterSidebar Agent リアルタイムテーマ作成：言葉で伝えるだけで着せ替え

以前は「プロンプトを外部AIに貼り付け → JSONを生成 → 設定画面に貼り付け」という面倒な手順が必要でした。
- 今は BetterSidebar Agent に自然な言葉で伝えるだけ：
  > *「マトリックス風のダーク＆ネオングリーンなサイバーパンクテーマを作って」* や *「柔らかく落ち着いた和風のミルクティー色にして」*
- Agent が配色トークンを自動構築し、**その場ですぐに適用（Apply）**してくれます！
- 背景が少し明るすぎる？「背景をもっと暗くして、枠線のコントラストを上げて」と会話を続けるだけでリアルタイムに修正。その日の気分に合わせたテーマで作業を楽しめます！

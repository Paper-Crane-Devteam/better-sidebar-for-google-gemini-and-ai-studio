# 🔧 v2.13.1 — Более читаемые результаты поиска и исправления для Gemini

Небольшое обновление после 2.13.0.

## ✨ Улучшения

*   **🔍 Результаты поиска стало проще читать:** Раньше в превью каждого результата показывался «сырой» Markdown, а найденный фрагмент часто обрезался в конце. Теперь превью — это чистый текст, совпадение показывается ближе к началу с небольшим контекстом перед ним, а строки больше не обрываются посреди слова. Если в сообщении несколько совпадений, показывается до двух фрагментов и общее число совпадений, а роль и дата больше не повторяются для каждого совпадения из одного сообщения.

## 🐞 Исправления

*   **📜 Страница Gemini «застревала» сдвинутой вверх:** Иногда вся страница смещалась вверх, а внизу оставалась пустая полоса до перезагрузки. Чаще это происходило при длинной истории чатов. Теперь исправлено.
*   **⌨️ Поле ввода перекрывалось рядом с Canvas / Deep Research:** Когда была открыта боковая панель, поле ввода могло частично прятаться за ней. Теперь оно сужается по доступной ширине.

Если что-то всё ещё выглядит не так, дайте знать. Спасибо ☕

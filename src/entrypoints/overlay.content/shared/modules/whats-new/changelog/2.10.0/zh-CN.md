## 🎁 先来聊聊大家都用得上的基础体验升级

日常用起来，顺手是最重要的。这次我给基础版塞了不少提升幸福感的小优化，就是想让大家用得更没有负担：

*   **AI Studio 也有“临时对话”了**：有朋友吐槽说，有时候就是想随便试探几个问题，不想留记录。这次安排上了！新对话不会记录到文件树里（不过实话实说，AI Studio Drive 还是会保存的，咱只是在前端模拟了临时的体验）。顺便也修了一个之前 Gemini 里临时对话会在文件夹乱建 entry 的小 bug。
*   **界面更清爽的“紧凑模式”**：如果你跟我一样，工作时恨不得把屏幕上多余的按钮全清空，现在你可以把侧边栏的图标栏完全隐藏掉了！界面瞬间清爽，认知负担减半，非常适合沉浸式工作。
*   **更跟手的鼠标和快捷键**：New chat 按钮现在支持鼠标中键了，中键一点，直接在新标签页打开对话；另外，键盘上的 F2 重命名、Delete 键删除文件，这些肌肉记忆终于也支持上了。
*   **找文件夹不眼花**：在文件夹选择弹窗里加了搜索功能，文件再多也能一秒定位，不用再瞎找了。
*   **顺手修了个小 Bug**：修了在 Gemini 里 branch chat 时，右侧滚动条（smartscrollbar）偶尔抽风顺序混乱的问题。

## 🔥 重头戏：Workspace Agent（让 AI 直接帮你干活）

这绝对是这次最让我兴奋的功能！我一直觉得，光聊天还是不够，AI 应该真正能帮我把活给干了。所以，Workspace Agent 来了！

**怎么用？非常简单：** 它和之前的 BetterSidebar Agent 是并列的。你只需要在输入框敲一个 `>` 符号，选择 Workspace Agent 就能直接唤起。你可以把手头的本地文件直接拖进工作区让它处理；**更强大的是，你完全可以什么文件都不用传，直接让 AI 从零给你新建文件！**

不管是让它帮你处理已有文件，还是从零凭空创建，它都能轻松搞定。**它到底能干嘛？我给大家举几个真实的例子：**

*   **📝 写论文/报告的救星 (支持 Word `.docx`)**
    你可以把几十页的 `thesis.docx` 拖进去，让 AI 帮你润色指定段落。重点来了：它**不会直接粗暴地覆盖你的原文件**，而是像导师一样，在出问题的地方给你加上**批注**，或者用**修订模式**（Tracked Changes）帮你改写。你辛苦调好的排版、参考文献统统不会乱，你只要在 Word 里一条条点“接受/拒绝”就行了。
*   **📊 数据处理带师 (支持 Excel `.xlsx` / `.csv`)**
    把 `data.xlsx` 丢给它，让它帮你做统计分析。它不仅能懂你的表头，甚至能聪明地在你的表格里**插入新列并写好真实的 Excel 公式**，而不是给你填死的一堆数字。你原来表格里的图表、条件格式完全不受影响。
*   **🎬 视频创作者的福音 (支持字幕 `.srt`, `.vtt`, `.ass`)**
    你可以让它帮你翻译或者润色字幕文件。最绝的是，它知道时间轴是不能碰的，翻译完之后，**时间轴连一毫秒都不会被破坏**，再也不用担心调字幕对不上口型了。
*   **📚 查阅和标注文献 (支持 PDF)**
    拖个 PDF 进去，虽然由于格式限制不能直接改正文的字，但它可以帮你提取信息，甚至直接在 PDF 上帮你**高亮重点、添加注释便签**。
*   **🪧 演示文稿小助手 (支持 PPT `.pptx`)**
    支持读取幻灯片内容，替换文案，修改演讲者备注，甚至还能帮你重新排版幻灯片的顺序。
*   **💻 程序员和写作党的最爱：不仅能改，还能从零「凭空造物」！(支持基础纯文本、Markdown 以及各种代码文件)**
    这是最容易被大家误解的一点——**千万别以为你必须先上传文件它才能工作！**
    对于所有文本与代码类文件（HTML、CSS、JS/TS、Python、Markdown 等），AI 不仅能精准定位与重构现有代码，**更可以直接从零为你创建新项目**。比如你直接跟它说：“帮我从零写一个完整的 React 待办小工具”，它会直接在工作区里建好 HTML、组件代码、样式表与配置文件，分分钟给你搓出一个前端项目来！在工作区里养了个专属的全能全栈打工人，完全没毛病。

**发现了吗？它最大的优势就是：绝不弄乱你的排版！** 得益于底层专门对文档格式的支持，不管它是改 Word 还是改 Excel，原有的样式通通被保护得很好。这才是真正的生产力工具该有的样子。

*   **关于格式支持的边界说明**：文本和代码类文件可以随意新建和修改；而像 Word、Excel、PPT、PDF 这些特殊的复合排版格式，目前专注于**在已有文件的基础上进行读取、润色与精准改动**（保证原有格式、图表和样式绝对不乱），这类特殊格式暂时需要你先上传原文件，目前还不支持直接凭空新建全新的 Word 或 Excel 文件。
*   **一点小遗憾和承诺**：受限于浏览器插件的环境限制，如果是要处理 Word/Excel 等已有文档，目前需要先手动拖入工作区；同时侧边栏里暂时还不支持直接在线富文本预览（需要下载或外部打开）。这些不方便的地方我都记在小本本上了，后续一定会想办法解决。
*   **有问题随时找我**：目前这个功能还在 Beta 测试阶段，大家用的时候遇到任何 bug，或者觉得哪里反人类，随时跟我反馈，我保证光速修复！

## 🚀 Power Users，请进（关于 Powerpack）

如果你是重度依赖 AI 生产力的硬核玩家（Power users），Workspace Agent 的完全体绝对值得拥有。

*   **解除封印**：在 Powerpack 里，工作区和文件数量完全没有限制，随便造。
*   **AI Studio 补齐短板**：现在 AI Studio 也支持完整的 Agent 功能了，拥有和 Gemini 完全一致的 Agent 体验。
*   **Agent 变聪明了**：我重新优化了 Agent 的系统指令。现在它交互性更强了，会跟你商量着来，不会再像以前那样傻乎乎地闷头自己干，更懂你的真实意图。

🤫 **私心划个重点（稍微推销一下）**：Workspace Agent 目前还在 Beta 期间。一旦测试结束、功能打磨稳定了，Powerpack 是会涨价的。所以，现在入手绝对不亏，不仅早买早享受，还能省一笔钱。就当是支持我继续爆肝啦！

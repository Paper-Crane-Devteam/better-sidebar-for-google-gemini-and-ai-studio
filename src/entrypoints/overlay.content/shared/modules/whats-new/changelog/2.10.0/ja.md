# 2.10.0 アップデート：Workspace Agent登場、そしてさらに快適になる体験の最適化

皆さんこんにちは、いつもの進捗報告の時間です。

最近は徹夜で 2.10.0 のアップデートに取り組んでいました。今回は皆さんがずっと言っていた不満点を解消しただけでなく、「Workspace Agent」というかなり大きな機能を追加しました。これが「生産性モンスター」への大きな一歩になると思うので、早速紹介させてください。

## 🎁 まずは全員が使える基本版の体験アップグレードから

毎日使うツールは、何より「使いやすさ」が大事です。今回は基本版にも、皆さんの負担を減らし、もっと快適に使えるような細かな最適化をたくさん詰め込みました。

*   **AI Studioにも「一時チャット」が来ました**：ちょっとした質問をしたいだけで、履歴に残したくない時ってありますよね。今回対応しました！新しいチャットはファイルツリーに記録されません（正直に言うと、AI Studio Driveには保存されますが、フロントエンドで一時的な体験をシミュレートしています）。ついでに、Geminiの一時チャットがフォルダに変なエントリーを作ってしまうバグも直しました。
*   **超スッキリの「コンパクトモード」**：僕みたいに、仕事中は画面上の不要なボタンを全部消したい派のあなたへ。サイドバーのアイコンバーを完全に隠せるようになりました！画面が一瞬でスッキリし、認知負荷が半減。集中したい時に最適です。
*   **マウスとショートカットの操作性が向上**：New chat ボタンがマウスの中クリックに対応しました。クリック一発で新しいタブでチャットが開きます。また、F2キーで名前変更、Deleteキーでファイル削除など、指が覚えているショートカットがついに使えるようになりました。
*   **フォルダ探しで迷わない**：フォルダ選択のポップアップに検索機能を追加しました。フォルダがいくら増えても、もう一瞬で見つかります。
*   **ついでに直したバグ**：Geminiで branch chat した時に、右側のスクロールバー（smartscrollbar）の順番がおかしくなる問題を修正しました。

## 🔥 目玉機能：Workspace Agent（AIが直接仕事をしてくれます）

これは今回、僕が一番興奮している機能です！ただチャットするだけじゃ物足りない、AIには実際に仕事の手を動かしてほしいとずっと思っていました。そこで、Workspace Agentの登場です！

**使い方は？超簡単です：** 以前のBetterSidebar Agentと並んでいます。入力欄で `>` 記号を打ち込み、Workspace Agentを選択するだけで呼び出せます。手元のファイルをドラッグ＆ドロップして作業させることもできますが、**さらに素晴らしいのは、何もファイルをアップロードせずに、AIにゼロから新規ファイルを作らせることもできる点です！**

既存ファイルを調整させる場合でも、ゼロから無の状態から作成させる場合でも、軽快にこなしてくれます。**一体何ができるのか？いくつかリアルな例を挙げますね：**

*   **📝 論文/レポート執筆の救世主 (Word `.docx` 対応)**
    数十ページの `thesis.docx` をドラッグして、指定した段落をAIにブラッシュアップさせることができます。ここがポイント：**元のファイルを強引に上書きすることはしません**。まるで指導教官のように、問題箇所に**コメント**を追加したり、**変更履歴**（Tracked Changes）を使って書き直してくれます。苦労して調整したレイアウトや参考文献は一切崩れず、Word上で一つずつ「承認/元に戻す」をクリックするだけで済みます。
*   **📊 データ処理の達人 (Excel `.xlsx` / `.csv` 対応)**
    `data.xlsx` を投げ込んで、統計分析をしてもらいましょう。ヘッダーを理解するだけでなく、あなたの表に**新しい列を挿入し、本物のExcel数式を書いてくれます**。単なる数字の羅列を埋め込むわけではありません。元の表のグラフや条件付き書式は全く影響を受けません。
*   **🎬 動画クリエイターの福音 (字幕 `.srt`, `.vtt`, `.ass` 対応)**
    字幕ファイルの翻訳や推敲も任せてください。最高なのは、AIが「タイムラインは絶対に触ってはいけない」と理解していることです。翻訳後も、**タイムラインは1ミリ秒たりとも破壊されません**。字幕の口パクが合わなくなる心配はもう不要です。
*   **📚 文献の確認とハイライト (PDF 対応)**
    PDFをドラッグすれば、フォーマットの制限上、本文の文字を直接修正することはできませんが、情報を抽出したり、PDF上に直接**ハイライトを引いたり、コメントの付箋を追加したり**することができます。
*   **🪧 プレゼンのお助け役 (PPT `.pptx` 対応)**
    スライドの内容を読み取り、テキストを置き換えたり、ノートを変更したり、さらにはスライドの順番を再編成したりすることも可能です。
*   **💻 エンジニア・ライターに大人気：編集だけでなく、ゼロからの「無から有の創造」も可能！ (プレーンテキスト、`.md`、各種コードファイル 対応)**
    ここは多くの人が誤解しやすいポイントです——**「ファイルをアップロードしないとAIが動かない」なんて思わないでください！**
    すべてのテキスト・コード系ファイル（HTML、CSS、JS/TS、Python、Markdownなど）について、AIは既存コードの精密な修正やリファクタリングだけでなく、**ゼロから新しいプロジェクトを立ち上げることも完全に可能**です。例えば「ReactでシンプルなToDoアプリをゼロから作って」と頼むだけで、HTML、コンポーネントコード、スタイルシート、設定ファイルまでワークスペース内に一瞬で構築してくれます！専属のフルスタックエンジニアがワークスペースに常駐している感覚です。

**お気づきですか？最大のメリットは「レイアウトを絶対に崩さない」ことです！** ドキュメントフォーマット専用の基盤処理のおかげで、WordでもExcelでも、元のスタイルは完全に保護されます。これぞ真の生産性ツールのあるべき姿です。

*   **対応フォーマットの範囲について**：テキストやコードファイルは自由にゼロから作成・編集できます。一方、Word、Excel、PPT、PDFなどの特殊な複合レイアウト形式については、現在**既存のファイルを読み取り、レイアウトやグラフを一切崩さずに推敲・修正すること**に特化しています。そのため、これらの特殊フォーマットについては既存ファイルのアップロードが必要で、ゼロからの完全新規生成にはまだ対応していません。
*   **少しの妥協と今後の約束**：ブラウザ拡張機能の環境制限により、既存のWord/Excelなどを処理する場合は事前にワークスペースへドラッグしていただく必要があり、またサイドバー上で直接リッチプレビューすることにはまだ対応していません（ダウンロードまたは外部で閲覧可能）。これらの不便な点はノートにメモしてあるので、今後必ず解決策を見つけます。
*   **問題があればいつでも連絡を**：現在この機能はベータテスト中です。使っていてバグに遭遇したり、使いにくいと感じた箇所があれば、いつでもフィードバックをください。光の速さで修正することを約束します！

## 🚀 Power Users、いらっしゃい（Powerpackについて）

あなたがAIの生産性に重度に依存しているハードコアなプレイヤー（Power users）なら、Workspace Agentの完全版は絶対に手に入れる価値があります。

*   **封印解除**：Powerpackでは、ワークスペースの数もファイルの数も無制限です。好きなだけ使ってください。
*   **AI Studioの弱点を補強**：現在、AI Studioでも完全なAgent機能をサポートしており、Geminiと全く同じAgent体験を得られます。
*   **Agentが賢くなりました**：Agentのシステム指示を再最適化しました。対話性がより強くなり、以前のように何も考えずにただタスクを実行し続けるのではなく、あなたと相談しながら、本当の意図をより深く理解してくれます。

🤫 **個人的なアピール（ちょっとした宣伝）**：Workspace Agentは現在ベータ期間中です。テストが終了し機能が安定したら、Powerpackは値上げされる予定です。なので、今手に入れるのは絶対に損ではありません。早く使えて楽しめる上に、お金も節約できます。僕の徹夜作業への支援だと思って、ぜひご検討を！

## 🎨 最後に、気分を変える新しい服を（テーマについて）

時には、綺麗なテーマに変えるだけで、コードを書いたりドキュメントを読んだりする時の気分が良くなるものです。

*   **6種類の高見えテーマを追加**（Supportpackテーマパックに含まれます）：作業中、より快適な体験ができることを保証します。
*   **カラーピッカーがより便利に**：わざわざ設定パネルを開く必要はもうありません。これからはフォルダのドロップダウンメニューから直接カスタムカラースタイルを選べるようになりました。
*   **UIの微調整**：AI Studioテーマでサイドバーの背景色がおかしかった問題を修正し、ようやく見た目がスッキリしました。また、サイドバーにアカウントのアイコン表示を追加しました。複数アカウントを使い分ける方には朗報です。現在のログイン状態が一目でわかり、アカウントの切り替えもさらに便利になりました。

# 2.10.0 更新：Workspace Agent 登場，以及一系列讓你更爽的體驗優化

各位老朋友好，又到了彙報進度的環節。

最近爆肝更新了 2.10.0 版本，這次不僅搞定了一些大家反饋已久的痛點，還搞了個“大動作”——Workspace Agent。這大概是我們邁向“生產力怪獸”非常關鍵的一步，趕緊來跟大家聊聊。

## 🎁 先來聊聊大家都用得上的基礎體驗升級

日常用起來，順手是最重要的。這次我給基礎版塞了不少提升幸福感的小優化，就是想讓大家用得更沒有負擔：

*   **AI Studio 也有“臨時對話”了**：有朋友吐槽說，有時候就是想隨便試探幾個問題，不想留記錄。這次安排上了！新對話不會記錄到文件樹裡（不過實話實說，AI Studio Drive 還是會保存的，咱只是在前端模擬了臨時的體驗）。順便也修了一個之前 Gemini 裡臨時對話會在資料夾亂建 entry 的小 bug。
*   **介面更清爽的“緊湊模式”**：如果你跟我一樣，工作時恨不得把螢幕上多餘的按鈕全清空，現在你可以把側邊欄的圖示欄完全隱藏掉了！介面瞬間清爽，認知負擔減半，非常適合沉浸式工作。
*   **更跟手的滑鼠和快捷鍵**：New chat 按鈕現在支援滑鼠中鍵了，中鍵一點，直接在新分頁打開對話；另外，鍵盤上的 F2 重新命名、Delete 鍵刪除檔案，這些肌肉記憶終於也支援上了。
*   **找資料夾不眼花**：在資料夾選擇彈窗裡加了搜尋功能，檔案再多也能一秒定位，不用再瞎找了。
*   **順手修了個小 Bug**：修了在 Gemini 裡 branch chat 時，右側捲軸（smartscrollbar）偶爾抽風順序混亂的問題。

## 🔥 重頭戲：Workspace Agent（讓 AI 直接幫你幹活）

這絕對是這次最讓我興奮的功能！我一直覺得，光聊天還是不夠，AI 應該真正能幫我把活給幹了。所以，Workspace Agent 來了！

**怎麼用？非常簡單：** 它和之前的 BetterSidebar Agent 是並列的。你只需要在輸入框敲一個 `>` 符號，選擇 Workspace Agent 就能直接喚起。你可以把手頭的本機檔案直接拖進工作區讓它處理；**更強大的是，你完全可以什麼檔案都不用傳，直接讓 AI 從零給你新建檔案！**

不管是讓它幫你處理已有檔案，還是從零憑空建立，它都能輕鬆搞定。**它到底能幹嘛？我給大家舉幾個真實的例子：**

*   **📝 寫論文/報告的救星 (支援 Word `.docx`)**
    你可以把幾十頁的 `thesis.docx` 拖進去，讓 AI 幫你潤色指定段落。重點來了：它**不會直接粗暴地覆蓋你的原檔案**，而是像導師一樣，在出問題的地方給你加上**批註**，或者用**修訂模式**（Tracked Changes）幫你改寫。你辛苦調好的排版、參考文獻統統不會亂，你只要在 Word 裡一條條點“接受/拒絕”就行了。
*   **📊 資料處理大師 (支援 Excel `.xlsx` / `.csv`)**
    把 `data.xlsx` 丟給它，讓它幫你做統計分析。它不僅能懂你的表頭，甚至能聰明地在你的表格裡**插入新列並寫好真實的 Excel 公式**，而不是給你填死的一堆數字。你原來表格裡的圖表、條件格式完全不受影響。
*   **🎬 影片創作者的福音 (支援字幕 `.srt`, `.vtt`, `.ass`)**
    你可以讓它幫你翻譯或者潤色字幕檔案。最絕的是，它知道時間軸是不能碰的，翻譯完之後，**時間軸連一毫秒都不會被破壞**，再也不用擔心調字幕對不上口型了。
*   **📚 查閱和標註文獻 (支援 PDF)**
    拖個 PDF 進去，雖然由於格式限制不能直接改正文的字，但它可以幫你提取資訊，甚至直接在 PDF 上幫你**高亮重點、添加註釋便籤**。
*   **🪧 簡報小助手 (支援 PPT `.pptx`)**
    支援讀取投影片內容，替換文案，修改演講者備註，甚至還能幫你重新排版投影片的順序。
*   **💻 工程師和寫作黨的最愛：不僅能改，還能從零「憑空造物」！(支援基礎純文字、Markdown 以及各種程式碼檔案)**
    這是最容易被大家誤解的一點——**千萬別以為你必須先上傳檔案它才能工作！**
    對於所有文字與程式碼類檔案（HTML、CSS、JS/TS、Python、Markdown 等），AI 不僅能精準定位與重構現有程式碼，**更可以直接從零為你建立新專案**。比如你直接跟它說：“幫我從零寫一個完整的 React 待辦小工具”，它會直接在工作區裡建好 HTML、組件程式碼、樣式表與設定檔，分分鐘給你搓出一個前端專案來！在工作區裡養了個專屬的全能全端打工人，完全沒毛病。

**發現了嗎？它最大的優勢就是：絕不弄亂你的排版！** 得益於底層專門對文件格式的支援，不管它是改 Word 還是改 Excel，原有的樣式統統被保護得很好。這才是真正的生產力工具該有的樣子。

*   **關於格式支援的邊界說明**：文字和程式碼類檔案可以隨意新建和修改；而像 Word、Excel、PPT、PDF 這些特殊的複合排版格式，目前專注於**在已有檔案的基礎上進行讀取、潤色與精準改動**（保證原有格式、圖表和樣式絕對不亂），這類特殊格式暫時需要你先上傳原檔案，目前還不支援直接憑空新建全新的 Word 或 Excel 檔案。
*   **一點小遺憾和承諾**：受限於瀏覽器外掛的環境限制，如果是要處理 Word/Excel 等已有文件，目前需要先手動拖入工作區；同時側邊欄裡暫時還不支援直接線上富文字預覽（需要下載或外部開啟）。這些不方便的地方我都記在小本本上了，後續一定會想辦法解決。
*   **有問題隨時找我**：目前這個功能還在 Beta 測試階段，大家用的時候遇到任何 bug，或者覺得哪裡反人類，隨時跟我反饋，我保證光速修復！

## 🚀 Power Users，請進（關於 Powerpack）

如果你是重度依賴 AI 生產力的硬核玩家（Power users），Workspace Agent 的完全體絕對值得擁有。

*   **解除封印**：在 Powerpack 裡，工作區和檔案數量完全沒有限制，隨便造。
*   **AI Studio 補齊短板**：現在 AI Studio 也支援完整的 Agent 功能了，擁有和 Gemini 完全一致的 Agent 體驗。
*   **Agent 變聰明了**：我重新優化了 Agent 的系統指令。現在它互動性更強了，會跟你商量著來，不會再像以前那樣傻乎乎地悶頭自己幹，更懂你的真實意圖。

🤫 **私心劃個重點（稍微推銷一下）**：Workspace Agent 目前還在 Beta 期間。一旦測試結束、功能打磨穩定了，Powerpack 是會漲價的。所以，現在入手絕對不虧，不僅早買早享受，還能省一筆錢。就當是支援我繼續爆肝啦！

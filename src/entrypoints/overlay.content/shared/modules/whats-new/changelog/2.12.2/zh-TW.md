# 🔧 v2.12.2 — 問題修復與更多語言

一個小更新，修了點問題，也加了點東西。

## 🐞 修復
*   **🔄 背景同步訊息不再卡住：** 之前如果某個對話已被刪除或不存在，背景同步會卡在那裡。現在會跳過它繼續往下走。

## ✨ 新增
*   **🌍 支援更多語言：** 新增德語、法語、義大利語、韓語、波蘭語和土耳其語。
*   **🔍 手動檢查新版本：** 在「關於」頁面裡加了一個檢查更新的入口。

## ⚡ 效能優化
*   **🪶 側邊欄更輕快了：** 以前重新命名、移動、加標籤或刪除一個東西，都會把所有資料重新載入一遍。現在只更新真正有變動的部分，其餘地方保持不動，不再跟著重繪。
*   **💬 Agent 回覆更順暢：** 回覆串流輸出的時候，頁面在背景做的多餘工作少了很多。
*   **📦 啟動更快：** 擴充功能體積小了一些，語言包的載入方式也更有效率了。

這次改動碰到了比較底層的程式碼，我已經盡量仔細測過了。如果你發現哪裡不對勁（例如清單沒更新、改完東西後有內容不見了），麻煩告訴我一聲，我會盡快修好。

## 💌 順便說一句
我又做了一個小擴充功能 **[Better Playlists](https://chromewebstore.google.com/detail/better-playlists-youtube/dbkjpepjgmodcoanoaokohenmkdldffa?utm_source=better-sidebar&utm_medium=extension&utm_campaign=changelog)**，用來更好地管理 YouTube 播放清單，有側邊欄，也支援批次移動、複製和刪除。如果你也常被亂糟糟的播放清單困擾，歡迎試試看。

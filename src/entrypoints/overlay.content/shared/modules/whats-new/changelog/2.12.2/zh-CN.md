# 🔧 v2.12.2 — 问题修复与更多语言

一个小更新，修了点问题，也加了点东西。

## 🐞 修复
*   **🔄 后台同步消息不再卡住：** 之前如果某个对话已经被删除或不存在，后台同步会卡在那里。现在会跳过它继续往下走。

## ✨ 新增
*   **🌍 支持更多语言：** 新增德语、法语、意大利语、韩语、波兰语和土耳其语。
*   **🔍 手动检查新版本：** 在「关于」页面里加了一个检查更新的入口。

## ⚡ 性能优化
*   **🪶 侧边栏更轻快了：** 以前重命名、移动、打标签或删除一个东西，都会把所有数据重新加载一遍。现在只刷新真正变了的部分，其余地方保持不动，不再跟着重绘。
*   **💬 Agent 回复更顺滑：** 回复流式输出的时候，页面在后台做的多余工作少了很多。
*   **📦 启动更快：** 扩展体积小了一些，语言包的加载方式也更高效了。

这次改动碰到了比较底层的代码，我已经尽量仔细测过了。如果你发现哪里不对劲（比如列表没更新、改完东西后有内容不见了），麻烦告诉我一声，我会尽快修好。

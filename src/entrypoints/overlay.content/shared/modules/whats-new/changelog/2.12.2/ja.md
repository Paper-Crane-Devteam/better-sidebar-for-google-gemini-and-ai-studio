# 🔧 v2.12.2 — 不具合修正と対応言語の追加

いくつかの修正と追加を含む小さなアップデートです。

## 🐞 修正
*   **🔄 バックグラウンドのメッセージ同期が止まらなくなりました：** 削除済み・存在しないチャットがあると同期がそこで止まることがありました。今はスキップして処理を続けます。

## ✨ 新機能
*   **🌍 対応言語を追加：** ドイツ語、フランス語、イタリア語、韓国語、ポーランド語、トルコ語に対応しました。
*   **🔍 手動でアップデートを確認：** 「概要」ページに確認用の入口を追加しました。

# 2.12.0 更新：标签终于能点开了、一键“换个新对话继续聊”，以及更让人放心的 Browser Agent

各位老朋友好 👋

这次是个小版本，比较像一次“打磨细节”。2.11.0 发出去之后，我自己每天都在用，用着用着就发现了几处不太顺手的地方，这次一起收拾了一下。

---

## ⚡ TL;DR（亮点速览）

1. **🏷️ 标签页可以点开了**：点击标签就能看到所有打了这个标签的对话，还能在里面快速切换标签、搜索、添加或移除标签。
2. **🔀 新对话继续**：对话聊得太长时，BetterSidebar Agent 可以帮你总结，并打开一个新对话，把总结放进输入框等你确认。
3. **✨ Agent 快捷开场白**：用 `>` 选好 Agent 后，输入框上方会出现一排按钮，告诉你它能做什么。
4. **🛡️ Browser Agent 权限更细**：标签页和书签的权限分开控制，也终于能看到你所有的窗口了。
5. **📚 “文件”改名为“库”**：存放所有对话的那个标签页换了个更贴切的名字，功能完全没变。
6. **🐛 修复 AI Studio 误报未登录**：明明已经登录，却弹出“未检测到账号”的问题修好了。

## 🔥 挑几个值得聊聊的

### 🏷️ 标签页终于能点开了

说实话，以前的标签页有点像个“死胡同”：能看到所有标签，但点了没反应，标签更像是装饰，而不是工具。

现在点击任意一个标签，就会打开所有打了这个标签的对话列表。在这里你可以：

- **快速切换标签**：直接在顶部切换到别的标签，不用退回列表。
- **标签内搜索**：一个标签下对话很多时，直接搜就行。
- **快捷操作**：一键把对话从当前标签移除；右键还能添加或移除其他标签、收藏等等。
- **在库中查看**：一键跳回这些对话所在的文件夹位置。

标签终于不只是“贴个标记”，而是真正能帮你找到东西了。

### 🔀 新对话继续：长对话也能干净地“接力”

这种感觉大家应该都有：一个对话聊得太久，模型开始“忘事”、抓不住重点，可重新开一个又得把前因后果手动再敲一遍。

现在你可以直接跟 BetterSidebar Agent 说（快捷按钮里也有）：*“总结这个对话，并在新对话里继续”*。它会整理一份交接说明：你想做什么、做过哪些决定以及原因、还有哪些问题没解决。然后在当前标签页旁边打开一个新对话，把这份总结放进输入框里。

这里有几点是我特别在意的：

- **不会自动发送**：总结只是放在输入框里，你可以先看一遍、改一改，再自己发出去。
- **打开前一定先问你**，每次都会。
- **同一个账号**：如果你登录了多个 Google 账号，新对话会在你当前使用的账号里打开，不会跑错地方。
- **原对话还在**：旧的那个标签页原样保留，总结漏了什么随时可以回去翻。

### ✨ 快捷开场白：选好 Agent，马上知道它能帮你做什么

我发现自己有个小习惯：输入 `>` 选好 Agent 之后，经常对着闪烁的光标愣一下，“嗯……我该让它干点啥？”所以现在，选好 Agent 的那一刻，输入框上方会出现一排小按钮，比如：

- **BetterSidebar Agent**：整理对话、查找对话、打标签、设计主题、新对话继续……
- **Workspace Agent**：总结文件、分析表格、对话存为笔记……
- **Browser Agent**：标签页分组、查找重复、收藏本窗口……

点一下，它会往输入框里放一句“说了一半”的话，比如 *“帮我做一个这种感觉的主题：”*，你接着把后半句打完就好。一开始打字，按钮就会悄悄让开。它们只是轻轻推你一把，不是固定台词。

### 🛡️ Browser Agent：权限更细，也能看到所有窗口了

**标签页和书签分开授权。** 以前的权限只有“整理”和“删除”两档，标签页和书签绑在一起。有朋友跟我说，愿意让 AI 帮忙整理标签页，但不太想让它碰收藏夹，这个顾虑完全能理解。所以现在 Browser Agent 设置里拆成了四个开关：整理标签页、关闭标签页、整理书签、删除书签。你放心交出去多少，就开多少。

**能跨所有窗口工作了。** 这个说实话是我这边的 Bug。之前 Browser Agent 只能看到当前对话所在的那个窗口，如果你的标签页分散在三四个窗口里（我自己就经常这样 😅），让它“清理重复标签页”基本会漏掉一大半。现在它会把每个窗口都看一遍再判断哪些算重复，并告诉你每一处改动发生在哪个窗口。另外，如果你把 Gemini 装成了独立的应用窗口来用，Agent 也能认出来，会在你平时的浏览器窗口里干活。

## 🛠️ 细节与修复

- **“文件”改名为“库”**：一直觉得用“文件”来称呼对话有点别扭，“库”更贴切一些。另外标签列表去掉了前面的小图标，名字能多显示几个字。
- **AI Studio 账号检测修复**：AI Studio 最近改版后，有些朋友明明已经登录，却还是弹出“未检测到账号”的提示，给大家添麻烦了，现在已经修好。

# 2.12.0 更新：標籤終於能點開了、一鍵「換個新對話繼續聊」，以及更讓人放心的 Browser Agent

各位老朋友好 👋

這次是個小版本，比較像一次「打磨細節」。2.11.0 發出去之後，我自己每天都在用，用著用著就發現了幾處不太順手的地方，這次一起收拾了一下。

---

## ⚡ TL;DR（亮點速覽）

1. **🏷️ 標籤分頁可以點開了**：點擊標籤就能看到所有加上這個標籤的對話，還能在裡面快速切換標籤、搜尋、加上或移除標籤。
2. **🔀 新對話繼續**：對話聊得太長時，BetterSidebar Agent 可以幫你總結，並開啟一個新對話，把總結放進輸入框等你確認。
3. **✨ Agent 快捷開場白**：用 `>` 選好 Agent 後，輸入框上方會出現一排按鈕，告訴你它能做什麼。
4. **🛡️ Browser Agent 權限更細**：分頁和書籤的權限分開控制，也終於能看到你所有的視窗了。
5. **📚「檔案」改名為「資料庫」**：存放所有對話的那個分頁換了個更貼切的名字，功能完全沒變。
6. **🐛 修正 AI Studio 誤報未登入**：明明已經登入，卻跳出「未偵測到帳號」的問題修好了。

## 🔥 挑幾個值得聊聊的

### 🏷️ 標籤分頁終於能點開了

老實說，以前的標籤分頁有點像個「死胡同」：看得到所有標籤，但點了沒反應，標籤比較像裝飾，而不是工具。

現在點擊任一個標籤，就會開啟所有加上這個標籤的對話列表。在這裡你可以：

- **快速切換標籤**：直接在頂部切換到別的標籤，不用退回列表。
- **標籤內搜尋**：一個標籤下對話很多時，直接搜就好。
- **快捷操作**：一鍵把對話從目前標籤移除；按右鍵還能加上或移除其他標籤、收藏等等。
- **在資料庫中檢視**：一鍵跳回這些對話所在的資料夾位置。

標籤終於不只是「貼個記號」，而是真的能幫你找到東西了。

### 🔀 新對話繼續：長對話也能乾淨地「接力」

這種感覺大家應該都有：一個對話聊得太久，模型開始「忘東忘西」、抓不住重點，可是重新開一個又得把前因後果手動再打一遍。

現在你可以直接跟 BetterSidebar Agent 說（快捷按鈕裡也有）：*「總結這個對話，並在新對話裡繼續」*。它會整理一份交接說明：你想做什麼、做過哪些決定以及原因、還有哪些問題沒解決。接著在目前分頁旁邊開啟一個新對話，把這份總結放進輸入框裡。

這裡有幾點是我特別在意的：

- **不會自動送出**：總結只是放在輸入框裡，你可以先看一遍、改一改，再自己送出。
- **開啟前一定先問你**，每次都會。
- **同一個帳號**：如果你登入了多個 Google 帳號，新對話會在你目前使用的帳號裡開啟，不會跑錯地方。
- **原對話還在**：舊的那個分頁原樣保留，總結漏了什麼隨時可以回去翻。

### ✨ 快捷開場白：選好 Agent，馬上知道它能幫你做什麼

我發現自己有個小習慣：輸入 `>` 選好 Agent 之後，常常對著閃爍的游標愣一下，「嗯……我該讓它做點什麼？」所以現在，選好 Agent 的那一刻，輸入框上方會出現一排小按鈕，例如：

- **BetterSidebar Agent**：整理對話、尋找對話、加標籤、設計主題、新對話繼續……
- **Workspace Agent**：總結檔案、分析表格、對話存成筆記……
- **Browser Agent**：分頁分組、尋找重複、收藏本視窗……

點一下，它會往輸入框裡放一句「說了一半」的話，例如 *「幫我做一個這種感覺的主題：」*，你接著把後半句打完就好。一開始打字，按鈕就會悄悄讓開。它們只是輕輕推你一把，不是固定台詞。

### 🛡️ Browser Agent：權限更細，也能看到所有視窗了

**分頁和書籤分開授權。** 以前的權限只有「整理」和「刪除」兩種，分頁和書籤綁在一起。有朋友跟我說，願意讓 AI 幫忙整理分頁，但不太想讓它碰書籤，這個顧慮完全能理解。所以現在 Browser Agent 設定裡拆成了四個開關：整理分頁、關閉分頁、整理書籤、刪除書籤。你放心交出去多少，就開多少。

**能跨所有視窗工作了。** 這個老實說是我這邊的 Bug。之前 Browser Agent 只能看到目前對話所在的那個視窗，如果你的分頁散落在三四個視窗裡（我自己就常常這樣 😅），請它「清理重複分頁」基本上會漏掉一大半。現在它會把每個視窗都看一遍再判斷哪些算重複，並告訴你每一處改動發生在哪個視窗。另外，如果你把 Gemini 裝成獨立的應用程式視窗來用，Agent 也認得出來，會在你平常的瀏覽器視窗裡做事。

## 🛠️ 細節與修正

- **「檔案」改名為「資料庫」**：一直覺得用「檔案」來稱呼對話有點彆扭，「資料庫」更貼切一些。另外標籤列表拿掉了前面的小圖示，名字能多顯示幾個字。
- **AI Studio 帳號偵測修正**：AI Studio 最近改版後，有些朋友明明已經登入，卻還是跳出「未偵測到帳號」的提示，給大家添麻煩了，現在已經修好。

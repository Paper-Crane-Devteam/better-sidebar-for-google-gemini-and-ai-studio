## ⚡ TL;DR（ハイライト）

1. **🏷️ タグが開けるように**：タグをクリックすると、そのタグが付いたチャットが一覧で見られます。タグの切り替え、検索、タグの追加・解除もその場でできます。
2. **🔀 新しいチャットで続ける**：チャットが長くなりすぎたら、BetterSidebar Agent が要約して、新しいチャットの入力欄に置いてくれます。
3. **✨ Agent のクイックスタート**：`>` で Agent を選ぶと、何ができるかを示すボタンが入力欄の上に並びます。
4. **🛡️ Browser Agent の権限がより細かく**：タブとブックマークの権限を別々に設定でき、すべてのウィンドウも見えるようになりました。
5. **📚「ファイル」が「ライブラリ」に**：すべてのチャットが入っているタブの名前を変えました。中身は同じです。
6. **🐛 AI Studio のログイン検出を修正**：ログインしているのに「アカウントが検出されません」と出る問題を直しました。

## 🔥 いくつか、もう少し詳しく

### 🏷️ タグが開けるようになりました

正直に言うと、これまでのタグタブはちょっと「行き止まり」でした。タグは見えるのにクリックしても何も起きないので、道具というより飾りのようでした。

今はタグをクリックすると、そのタグが付いたチャットの一覧が開きます。そこでは：

- **タグを切り替え**：一覧に戻らず、上部からそのまま別のタグへ。
- **タグ内を検索**：チャットが多いタグでもすぐ見つかります。
- **クイック操作**：ワンクリックでこのタグから外せるほか、右クリックで他のタグの追加・解除やお気に入り登録などもできます。
- **ライブラリで表示**：そのチャットがフォルダのどこにあるかへすぐ移動できます。

タグが「印を付けるだけ」ではなく、ちゃんと「探すための道具」になった気がします。

### 🔀 新しいチャットで続ける：長い会話もすっきりバトンタッチ

こんな経験はありませんか。会話が長くなるにつれてモデルが話の筋を見失い始め、でも新しく始めるには経緯を全部打ち直さないといけない。

今は BetterSidebar Agent に *「このチャットを要約して、新しいチャットで続けて」* と頼むだけです（クイックスタートのボタンにもあります）。やりたいこと、決めたこととその理由、まだ残っている課題をまとめた引き継ぎメモを書き、今のタブのすぐ隣に新しいチャットを開いて、その要約を入力欄に置いてくれます。

ここで大事にしたのは次の点です：

- **勝手には送信しません**。要約は入力欄に置かれるだけなので、読んで直してから自分で送れます。
- **タブを開く前に必ず確認します**。毎回です。
- **同じアカウントで開きます**。複数の Google アカウントにログインしていても、今使っているアカウントで新しいチャットが開きます。
- **元のチャットはそのまま**。要約に漏れがあれば、いつでも戻って確認できます。

### ✨ クイックスタート：Agent を選んだ瞬間に、何ができるか分かる

`>` を打って Agent を選んだあと、点滅するカーソルを前に「さて……何を頼もうかな」と固まってしまうことがよくありました。そこで、Agent を選ぶと入力欄の上に小さなボタンが並ぶようにしました。たとえば：

- **BetterSidebar Agent**：チャットを整理、チャットを探す、タグ付け、テーマを作る、新しいチャットで続ける…
- **Workspace Agent**：ファイルを要約、表を分析、チャットをメモに…
- **Browser Agent**：タブをグループ化、重複を探す、ウィンドウを保存…

クリックすると *「こんな雰囲気のテーマを作って：」* のような書きかけの一文が入るので、続きを打つだけです。入力を始めるとボタンはそっと消えます。あくまで軽いきっかけで、台本ではありません。

### 🛡️ Browser Agent：より細かい権限と、すべてのウィンドウ

**タブとブックマークを別々に許可。** これまでの権限は「整理」と「削除」の2つだけで、タブとブックマークがひとまとめでした。「タブの整理は任せたいけど、ブックマークには触ってほしくない」という声をいただいて、それはもっともだと思いました。そこで Browser Agent の設定を、タブを整理・タブを閉じる・ブックマークを整理・ブックマークを削除の4つのスイッチに分けました。任せてもいいと思える分だけオンにしてください。

**すべてのウィンドウで動くように。** 正直に言うと、これは私のバグでした。これまでは会話を開いているウィンドウしか見られなかったので、タブが3つのウィンドウに散らばっていると（私はよくそうなります 😅）、「重複タブを閉じて」と頼んでも大半を見落としていました。今は全ウィンドウに目を通してから重複を判断し、どの変更がどのウィンドウに対するものかも教えてくれます。Gemini をアプリとしてインストールして専用ウィンドウで使っている場合も、ちゃんと理解して通常のブラウザウィンドウで作業します。

## 🛠️ 細かな改善と修正

- **「ファイル」が「ライブラリ」に**：会話を「ファイル」と呼ぶのが前から少し気になっていて、「ライブラリ」のほうがしっくりきます。タグ一覧からも先頭の小さなアイコンを外したので、名前が少し長く表示できます。
- **AI Studio のアカウント検出**：最近の AI Studio のリニューアル以降、ちゃんとログインしているのに「アカウントが検出されません」と表示されることがありました。ご迷惑をおかけしました。修正済みです。

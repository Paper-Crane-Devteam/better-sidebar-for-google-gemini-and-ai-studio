# 🔧 v2.13.2 — 指示欄でプロンプトライブラリが使えるように & Gemini の記録を修正
2.13.1 に続く小さなアップデートです。新機能がひとつ、いくつかの修正、そして次に向けたちょっとした予告があります。
## ✨ 新機能
*   **📚 指示欄でプロンプトライブラリを使う：** Gem エディタ、Notebook の設定、AI Studio のシステム指示に **Prompts** ドロップダウンが追加されました。検索やフォルダから選び、変数を入力してプロンプトを追記できます（取り消したいときはトーストから元に戻せます）。ドロップダウンの横には全文のプレビューが表示されます。**プロンプトとして保存** ボタンもあり、これらの入力欄でも `/` が使えるようになりました。
*   **🔀 AI Studio のシステム指示：** AI Studio 標準のリストと Better Sidebar のライブラリを切り替えられます。初回は AI Studio に保存済みの指示を一度だけ、重複なしで取り込みます。ライブラリモードでは専用の「⚡ Better Sidebar」項目にだけ書き込むので、ほかの指示には手を触れません。
## 🐞 修正
*   **💬 Gemini の新しいチャットが保存されない問題：** 10 月 20 日に Gemini がメッセージの送信方法をまた変更したため、新しいチャットや返信がサイドバーに届かなくなっていました。再び記録されるようになりました。
*   **✏️ AI Studio で名前の変更が元に戻る問題：** サイドバーで名前を変えたチャットが、次の返信のあとに元のタイトルへ戻ることがありました。新しい名前が保たれるようになりました。
*   **🪟 メニューが AI Studio のパネルに隠れる問題：** ポップオーバー、ダイアログ、トースト、ツールチップが AI Studio のサイドドロワーの裏に隠れることがありました。常に前面に表示されるようになりました。
*   **🖱 右クリックメニューのちらつき：** 右クリックメニューが一瞬別の位置に表示されてからポインタの位置へ移ることがありました。今はクリックした場所にそのまま開きます。
*   **🔍 検索プレビューのハイライト漏れ：** Markdown 記法（`**太字**` など）を含む検索や、書式をまたぐ正規表現は、ヒットはしてもプレビューでハイライトされませんでした。正しくハイライトされるようになりました。
*   **💾 データベースのバックアップがダウンロードできない問題：** Chrome がバックアップファイルのダウンロードをブロックすることがありました。エクスポート後はトーストでダウンロードのクリックを待つようになりました。
*   **🧭 アウトラインのカーソル：** 展開できる項目にだけポインタカーソルが表示されるようになりました。
## 🔭 予告：Web Agent
最近、Chrome のサイドパネルから AI がウェブページを操作してくれる **Web Agent** を作っています。ページを読んだり、クリックや入力をしたり、タブを行き来したりでき、その様子はいつでも確認・停止できます。小さな連携用拡張機能 **Better Sidebar Web Agent Connector** と一緒に動く仕組みで、こちらがまだ Chrome ウェブストアの審査待ちのため、今は機能を非表示にしています。承認され次第すぐに有効にしますので、楽しみにしていただけたらうれしいです。

# 🔧 v2.13.2 — 指令框接入提示詞庫，以及 Gemini 記錄修復
2.13.1 之後的一個小更新：一個新功能、幾處修復，還有一點關於下一步的預告。
## ✨ 新功能
*   **📚 在指令框裡使用提示詞庫：** Gem 編輯器、Notebook 設定和 AI Studio 的系統指令裡都多了一個 **Prompts** 下拉選單。可以搜尋或按資料夾瀏覽、填寫變數，然後把提示詞附加進去（反悔了可以在提示裡復原）。下拉框旁邊會顯示完整內容的預覽。另外還有 **儲存為提示詞** 按鈕，`/` 在這些輸入框裡也能用了。
*   **🔀 AI Studio 系統指令：** 可以在 AI Studio 內建的清單和 Better Sidebar 提示詞庫之間切換。第一次使用時，會把你在 AI Studio 裡儲存的指令匯入一次，並自動去重。在提示詞庫模式下，擴充功能只會寫入一個專門的「⚡ Better Sidebar」項目，不會動到你其他的指令。
## 🐞 修復
*   **💬 Gemini 新對話沒有被記錄：** Gemini 在 10 月 20 日又改了傳送訊息的方式，導致新對話和回覆沒有同步到側邊欄。現在可以正常記錄了。
*   **✏️ AI Studio 重新命名被還原：** 在側邊欄裡重新命名的對話，下一次回覆之後可能會變回舊標題。現在新名稱會保留下來。
*   **🪟 選單被 AI Studio 面板擋住：** 彈出框、對話框、提示和懸浮提示有時會被 AI Studio 的側邊抽屜蓋住。現在會始終顯示在最上層。
*   **🖱 右鍵選單閃爍：** 右鍵選單有時會先在錯誤的位置閃一下，再跳到滑鼠處。現在會直接在點擊的位置開啟。
*   **🔍 搜尋預覽缺少醒目標示：** 包含 Markdown 語法（例如 `**粗體**`）或跨格式的正規表示式搜尋，雖然能搜到，但預覽裡沒有醒目標示。現在會正確標示了。
*   **💾 資料庫備份下載被攔截：** Chrome 有時會攔截備份檔案的下載。現在匯出完成後會在提示裡等你點擊下載。
*   **🧭 大綱滑鼠樣式：** 現在只有可以展開的項目才會顯示手形游標。
## 🔭 預告：Web Agent
我最近一直在做一個 **Web Agent**，讓 AI 在 Chrome 側邊面板裡幫你操作網頁：閱讀頁面、點擊、輸入、在分頁之間切換，過程中你可以隨時查看、隨時叫停。它需要搭配一個小的配套擴充功能 **Better Sidebar Web Agent Connector** 使用，目前還在等 Chrome 線上應用程式商店審核，所以這個功能暫時先隱藏了。審核通過後我會第一時間開啟，希望到時候你會喜歡。

## 🌐 重點介紹：全新的 Web Agent 能幫你做什麼？

簡單來說，Web Agent 就像是坐在你身邊的一個 AI 助理。它直接執行在你的瀏覽器側邊欄裡，能夠理解你在目前網頁上看到的內容，並依照你的指令幫你執行操作。

**常見的使用情境：**
* **資訊擷取與整理**：把長網頁裡的零散資料一鍵整理成規整的表格。
* **分步表單代填**：依照你的要求，逐步在一個個輸入框中填入對應內容。
* **多頁面聯動**：在同一個網站的不同分頁之間切換比對，甚至直接在目標網站的站內搜尋框裡查找資訊，而不是胡亂去外部亂搜。

### 如何快速開始使用？
1. **安裝配套輕量擴充功能**：Web Agent 需要搭配一個專門的小擴充功能 —— **[Better Sidebar Web Agent Connector](https://chromewebstore.google.com/detail/dmogbaiecikhmldgdpapobncijaoeamc)** 一起工作。
   > **為什麼需要多裝一個擴充功能？**
   > 這是為了你的安全考量。操控網頁所需的底層偵錯權限被嚴格隔離在這個獨立的小擴充功能中；Better Sidebar 主擴充功能本身並不持有這些高風險權限。而且，這個小擴充功能被設計為**只回應來自 Better Sidebar 的指令**，杜絕外部惡意呼叫。
2. **首次授權**：初次啟動時，介面會跳出詳細的風險提示。請在仔細閱讀並點擊同意後開啟（之後在設定中隨時可以一鍵關閉撤回）。
3. **喚起指令**：在側邊欄的對話輸入框中直接輸入 `>Web` 並加上你的要求，就能把任務派給它了。
4. **環境需求**：目前僅支援 Google Chrome 瀏覽器。

## ⚠️【請務必閱讀】Web Agent 的安全與免責聲明

我們堅持把「醜話說在前面」。Web Agent 是一把非常鋒利的工具，能力強大的同時，也伴隨著不可忽視的潛在風險。請你在使用前花一分鐘認真了解以下事實：

- **⚠️ 它是以你本人的登入身分在操作**：
  Web Agent 執行在你真實的瀏覽器環境中，使用的是你目前已經登入的帳號狀態。這意味著：它送出的表單、傳送的訊息甚至是點擊購買，在對方網站看來都等同於**你本人的真實操作**。部分操作一旦送出是無法撤回的。
- **⚠️ 網頁的部分可見內容會被傳送給 AI 處理**：
  為了讀懂頁面，它擷取到的文字描述、超連結以及表單結構，都會作為上下文傳送給 Gemini 模型（背後由 Google 提供服務）。不過請放心，**密碼輸入框（type="password"）裡的內容受到底層保護，絕對不會被讀取**。
- **⚠️ 小心惡意網頁的「間接指令注入」（Prompt Injection）**：
  網路上的網頁環境錯綜複雜。某些惡意網頁可能會在內文中隱藏針對大型模型的惡意提示詞，試圖誘導 AI 做出非預期的行為。因此，**在造訪不熟悉的陌生網站時，請務必格外留神**。
- **🚫 嚴禁在極度敏感的頁面上開啟**：
  **請絕對不要**在涉及網路銀行、真實付款結帳、個人醫療紀錄、帳號安全與密碼修改等關鍵頁面上使用 Web Agent。
- **👀 AI 並非絕對可靠，請務必保持人工在場監督**：
  大型模型有可能理解錯按鈕的含義，或者誤讀了網頁結構。為此，我們在底層做了一道安全鎖：**每一個具體的點擊動作、每一次文字輸入、每一段修改頁面的腳本，都會在介面上暫停，等待你親眼確認並點擊同意後才會真正執行**。在它工作期間，請不要離開螢幕。
- **🛑 緊急終止手段隨時可用**：
  當 Web Agent 正在控制網頁時，Chrome 瀏覽器頂部會出現一條醒目的系統黃條提示（`"已開始對這個瀏覽器進行偵錯"`）。如果你發現 AI 表現異常，只需點擊該黃條上的**「取消」**按鈕，或者**直接在側邊欄關閉目前對話**，所有自動化控制都會立刻被強制切斷。
- **📄 責任與條款**：
  你在介面上確認執行的每一步操作，其結果均由你本人負責，同時也請遵守你所造訪網站的《使用者服務條款》。Better Sidebar 擴充功能依「現狀」提供，對經由使用者確認後執行的操作所引發的直接或間接後果不承擔連帶責任。

這些條款讀起來雖然有些生硬嚴肅，但對你坦誠相待、把潛在風險清清楚楚擺在桌面上，是我們對每一位使用者負責的底線。

## 🪟 浮動大綱檢視體驗升級

- **滑鼠離開自動淡出**：當你把滑鼠移出大綱區域幾秒後，它會自動收起摺疊為一個小小的標題列，把寶貴的螢幕空間留給對話內文，不再遮擋視線。需要它時，把滑鼠重新停留在標題列上就會立刻展開。
- **一鍵圖釘固定**：如果你正在精讀長文、希望大綱一直常駐顯示，只需點擊標題列上的「圖釘」圖示，就可以鎖定展開狀態。
- **更順手的快捷入口**：點擊右側圓點捲軸展開後，頂部新增了一個專屬快捷按鈕，點一下就能快速喚起浮動大綱。

- **其他細節優化**：
  - 優化了新手引導流程，新增了關於 Agent、程式碼片段、筆記本以及 Spark 功能的分步指引。
  - 優化了懸浮提示（Tooltip）的邊緣偵測邏輯，當螢幕邊緣空間不足時會自動翻轉到另一側顯示，同時限制了大綱超長提示的最大高度，避免超出螢幕。

## 🌐 重点介绍：全新的 Web Agent 能帮你做什么？

简单来说，Web Agent 就像是坐在你身边的一个 AI 助理。它直接运行在你的浏览器侧边栏里，能够理解你在当前网页上看到的内容，并按照你的指令帮你执行操作。

**常见的使用场景：**
* **信息提取与整理**：把长网页里的零散数据一键整理成规整的表格。
* **分步表单代填**：按照你的要求，逐步在一项项输入框中填入对应内容。
* **多页面联动**：在同一个网站的不同标签页之间切换比对，甚至直接在目标网站的站内搜索框里查找信息，而不是胡乱去外部瞎搜。

### 如何快速开始使用？
1. **安装配套轻量扩展**：Web Agent 需要配合一个专门的小扩展 —— **[Better Sidebar Web Agent Connector](https://chromewebstore.google.com/detail/dmogbaiecikhmldgdpapobncijaoeamc)** 一起工作。
   > **为什么需要多装一个扩展？**
   > 这是为了你的安全考虑。操控网页所需的底层调试权限被严格隔离在这个独立小扩展中；Better Sidebar 主插件本身并不持有这些高风险权限。而且，这个小扩展被设计为**只响应来自 Better Sidebar 的指令**，杜绝外部恶意调用。
2. **首次授权**：初次启动时，界面会弹出详细的风险提示。请在仔细阅读并点击同意后开启（后续在设置中随时可以一键关闭撤回）。
3. **唤起指令**：在侧边栏的对话输入框中直接输入 `>Web` 并加上你的要求，就能把任务派发给它了。
4. **环境要求**：目前仅支持 Google Chrome 浏览器。

## ⚠️【请务必阅读】Web Agent 的安全与免责声明

我们坚持把“丑话说在前面”。Web Agent 是一把非常锋利的工具，能力强大的同时，也伴随着不可忽视的潜在风险。请你在使用前花一分钟认真了解以下事实：

- **⚠️ 它是以你本人的登录身份在操作**：
  Web Agent 运行在你的真实浏览器环境中，使用的是你当前已经登录的账号状态。这意味着：它发出的表单提交、消息发送甚至是点击购买，在对端网站看来都等同于**你本人的真实操作**。部分操作一旦提交是不可撤回的。
- **⚠️ 网页的部分可见内容会被发送给 AI 处理**：
  为了读懂页面，它抓取到的文字描述、超链接以及表单结构，都会作为上下文发送给 Gemini 模型（背后由 Google 提供服务）。不过请放心，**密码输入框（type="password"）里的内容受到底层保护，绝对不会被读取**。
- **⚠️ 小心恶意网页的“间接指令注入”（Prompt Injection）**：
  互联网上的网页环境错综复杂。某些恶意网页可能会在正文中隐藏针对大模型的恶意提示词，试图诱导 AI 做出非预期的行为。因此，**在访问不熟悉的陌生网站时，请务必格外留神**。
- **🚫 严禁在极度敏感的页面上开启**：
  **请绝对不要**在涉及网上银行、真实支付结算、个人医疗档案、账号安全与密码修改等关键页面上使用 Web Agent。
- **👀 AI 并非绝对可靠，请务必保持人工在场监督**：
  大模型有可能理解错按钮的含义，或者误读了网页结构。为此，我们在底层做了一道安全锁：**每一个具体的点击动作、每一次文本输入、每一段修改页面的脚本，都会在界面上暂停，等待你肉眼确认并点击同意后才会真正执行**。在它工作期间，请不要离开屏幕。
- **🛑 紧急终止手段随时可用**：
  当 Web Agent 正在控制网页时，Chrome 浏览器顶部会出现一条醒目的系统黄条提示（`"已开始调试此浏览器"`）。如果你发现 AI 表现异常，只需点击该黄条上的**「取消」**按钮，或者**直接在侧边栏关闭当前对话**，所有自动化控制都会被立刻强行切断。
- **📄 责任与条款**：
  你在界面上确认执行的每一步操作，其结果均由你本人负责，同时也请遵守你所访问网站的《用户服务条款》。Better Sidebar 插件按“现状”提供，对经由用户确认后执行的操作所引发的直接或间接后果不承担连带责任。

这些条款读起来虽然有些生硬严肃，但对你坦诚相待、把潜在风险清清楚楚摆在桌面上，是我们对每一位用户负责的底线。

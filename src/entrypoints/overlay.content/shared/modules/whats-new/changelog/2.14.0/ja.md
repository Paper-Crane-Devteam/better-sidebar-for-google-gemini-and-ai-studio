# 2.14.0 アップデート：Web Agent がついに公開、全員に Power Pack を 3 日間プレゼント

皆さん、こんにちは 👋

前回予告した、ブラウザの中で作業をこなしてくれる Web Agent を覚えていますか？うれしいお知らせです。その連携用の拡張機能が Chrome ウェブストアの審査を通過しました。このバージョンから、Web Agent を正式に皆さんへ公開します。

1. 🌐 **Web Agent が登場**：ブラウザのサイドバーで AI がアシスタントになり、ページの閲覧、フォーム入力、データの抽出を手伝います。大事な操作は一つひとつ、あなたの確認を待ってから実行されます。

## 🌐 新しい Web Agent でできること

ひと言でいえば、Web Agent は隣に座っている AI アシスタントのようなものです。ブラウザのサイドバーで動き、今見ているページの内容を理解して、あなたの指示どおりに操作を行います。

**よくある使い方：**
* **情報の抽出と整理**：長いページに散らばったデータを、きれいな表にまとめます。
* **フォームの段階的な入力**：指示に従って、入力欄を一つずつ埋めていきます。
* **複数ページにまたがる作業**：同じサイトのタブを切り替えて比較したり、外部の検索に頼らずサイト内の検索ボックスで直接探したりします。

### はじめかた
1. **小さな連携用拡張機能をインストール**：Web Agent は **[Better Sidebar Web Agent Connector](https://chromewebstore.google.com/detail/dmogbaiecikhmldgdpapobncijaoeamc)** と一緒に動作します。
   > **なぜ拡張機能がもう一つ必要なの？**
   > あなたの安全のためです。ページの操作に必要な低レベルのデバッグ権限は、この独立した拡張機能に切り離されていて、Better Sidebar 本体はその高リスクな権限を持ちません。また、この拡張機能は**Better Sidebar からの命令にしか応答しない**よう作られているため、外部から悪用されることはありません。
2. **初回の許可**：初めて起動すると、詳しいリスクの説明が表示されます。よく読んでから同意してください（設定からいつでもオフに戻せます）。
3. **タスクを頼む**：サイドバーのチャット入力欄で `>Web` に続けて依頼内容を入力します。
4. **動作環境**：現在は Google Chrome のみ対応しています。

## ⚠️【必ずお読みください】Web Agent の安全性と免責事項

大事なことは先にお伝えしておきたいと思います。Web Agent はとても鋭い道具で、強力な反面、見過ごせないリスクもあります。使う前に 1 分だけ、次の点をご確認ください。

- **⚠️ あなた本人のログイン状態で操作します**：
  Web Agent は実際のブラウザ上で、現在ログインしているアカウントのまま動作します。つまり、フォームの送信やメッセージの送信、購入ボタンのクリックまで、相手のサイトからは**あなた本人の操作とまったく同じ**に見えます。送信後に取り消せない操作もあります。
- **⚠️ ページの一部の表示内容が AI に送信されます**：
  ページを理解するため、読み取ったテキスト、リンク、フォームの構造が、コンテキストとして Gemini モデル（Google が提供するサービス）に送信されます。なお、**パスワード欄（type="password"）の内容は保護されており、読み取られることはありません**。
- **⚠️ 悪意あるページの「プロンプトインジェクション」に注意**：
  ウェブの世界はさまざまです。悪意のあるページは、AI モデル向けの指示を本文に隠し、意図しない動作をさせようとすることがあります。**見慣れないサイトでは特に注意してください。**
- **🚫 極めて重要なページでは絶対に使わないでください**：
  オンラインバンキング、実際の決済画面、個人の医療記録、アカウントのセキュリティやパスワード変更などのページでは、**Web Agent を使わないでください**。
- **👀 AI は完璧ではありません。必ずそばで見守ってください**：
  モデルはボタンの意味を取り違えたり、ページの構造を誤解したりすることがあります。そのため安全ロックを設けています。**クリック、テキスト入力、ページを変更するスクリプトは、すべて一度止まり、あなたが目で確認して承認してから実行されます。** 作業中は画面から離れないでください。
- **🛑 緊急停止はいつでもできます**：
  Web Agent がページを操作している間、Chrome の上部に、ブラウザがデバッグされていることを示すシステムバー（`"このブラウザのデバッグを開始しました"`）が表示されます。AI の様子がおかしいと感じたら、そのバーの**「キャンセル」**を押すか、**サイドバーで現在の会話を閉じれば**、自動操作はすぐに断ち切られます。
- **📄 責任と規約**：
  あなたが確認して実行した各操作の結果はご自身の責任となります。また、訪問先サイトの利用規約を守ってご利用ください。Better Sidebar は「現状のまま」提供され、ユーザーの確認後に実行された操作による直接的・間接的な結果について責任を負いません。

少し硬く感じる内容かもしれませんが、正直にリスクをはっきりお伝えすることが、ユーザーの皆さんに対する私たちの最低限の責任だと考えています。

## 📁 Gems とノートブック：ついにフォルダで整理できるように

Gem やノートブックが増えるにつれ、探しにくくなったという声を多くいただきました。これからは整理がぐっと楽になります。

- **ツリー構造のフォルダ**：多階層のフォルダを自由に作成、名前変更でき、よく使うフォルダはピン留めできます。
- **ドラッグで並べ替え**：Gem やノートブックをマウスで好きなフォルダへドラッグできます。新しい「カスタム順」表示で、並びを思いどおりに決められます。
- **選択メニューもフォルダに連動**：拡張機能内の選択ダイアログやドロップダウンでも、同じフォルダツリーで表示されるので、すぐに見つかります。
- **誤削除の防止**：中身が空のフォルダだけを削除できるので、うっかり一式を消してしまう心配はありません。

## 🪟 フローティングアウトラインの改善

- **マウスが離れると自動でフェードアウト**：アウトラインからマウスを外して数秒たつと、小さなタイトルバーに折りたたまれ、画面を会話に譲ります。タイトルバーにマウスを乗せるとすぐに開きます。
- **ピンで固定**：長文をじっくり読むときなど、アウトラインを表示したままにしたい場合は、タイトルバーのピンアイコンをクリックすると展開状態を固定できます。
- **より便利な入口**：右側のドットスクロールバーを展開すると、上部に新しいボタンが加わり、ワンクリックでフローティングアウトラインを開けます。

## 🐛 修正と細かな改善

- **Gemini の会話が同期されない問題を修正**：10 月 21 日に行われた Gemini のフロントエンド改修に急ぎ対応し、新しい会話や返信が再びサイドバーへ安定して同期されるようになりました。
- **AI Studio の保存ボタンとドロワーの改善**：
  - サイドバーを展開しているときや会話エリアが狭いときに、スニペット保存ボタンが切れて隠れてしまう不具合を修正しました。
  - AI の「思考プロセス（Thinking Process）」の吹き出しに表示されていた反応しないボタンを削除しました。保存ボタンは各返信の一番上にそろって表示されます。
  - サイドバーを閉じている状態で、保存した項目をドラッグしてもフォルダのドロワーが開かない問題を修正しました。
- **AI Studio サイドバーのアニメーションを改善**：開閉アニメーションを作り直し、コマ落ちやカクつきがなくなりました。
- **更新通知が閉じられない問題を修正**：バックグラウンドのタブで拡張機能が静かに更新されたあと、表示中のページの更新通知がクリックできず閉じられないことがある不具合を修正しました。
- **より徹底したデータリセット**：設定の「データをリセット」で、ノートブックやスニペットのメタデータが残り、リセット直後に同期エラーが出ることがありました。リセットはすべてを完全に消去し、新規インストールと同じ状態になります。
- **翻訳の補完**：内蔵の 12 言語すべてを見直し、抜けていた項目を補い、不自然な機械翻訳を多数修正しました。
- **その他の細かな改善**：
  - 初回ガイドに、Agent、スニペット、ノートブック、Spark のステップごとの案内を追加しました。
  - ツールチップは画面端に余裕がないとき反対側に表示されるようになり、長すぎるアウトラインのツールチップには最大の高さを設けて画面からはみ出さないようにしました。

Gemini & AI Studio 一站式对话管理工具：文件夹整理、全文搜索、对话导出、AI Agent 自动化、提示词库、Google Drive 云同步、主题美化。
在一个插件中轻松管理 AI 对话的收藏、归档、搜索和备份。现在，你还可以尝试让 AI 助手为你分担一些整理工作。

BETTER SIDEBAR FOR GEMINI & AI STUDIO 希望能成为你得力的助手，为你提升工作效率。我们努力将原本简单的列表结构转化为一个更有条理的知识库，让你的 AI 工作流更加顺畅。

🔥 最新更新 (v2.10.0)

💼 Workspace Agent (让 AI 直接帮你编辑文件)：
• 这是一个非常关键的功能！输入 ">" 唤起 Workspace Agent，将文件（支持 Word, Excel, PDF, 字幕, 纯文本, Markdown 及各类代码文件等）拖入工作区，Agent 即可直接帮你查看、分析甚至编辑它们。
• 最大的亮点是“绝不弄乱排版”。它基于修订和精确替换（而非暴力覆盖），让你原有的表格公式、Word 样式、字幕时间轴等均得到完美保护。
• 目前由于浏览器限制，需先上传文件且暂不支持直接预览。此功能正处于 Beta 阶段，解锁 Powerpack 可享无限容量。

✨ 体验优化：
• 紧凑模式：可选择完全隐藏侧边栏图标栏，瞬间获得极致清爽的沉浸式工作界面。
• 临时对话扩展：AI Studio 新增模拟“临时对话”体验，随意测试不留痕迹（不会记录到文件树）。同时修复了 Gemini 临时对话偶尔在文件夹乱建条目的问题。
• 快捷操作提升：New chat 按钮现支持鼠标中键快速在新标签页打开；新增 F2 快捷重命名和 Delete 快捷删除，顺应你的肌肉记忆。
• 文件夹秒搜：文件夹选择弹窗新增搜索功能，文件再多也能一秒定位。
• 界面与交互：修复了分支对话时智能滚动条顺序混乱的问题；AI Studio 主题侧边栏背景颜色已修正；侧边栏新增账号头像显示，多账号切换一目了然。
• 新增 6 款高颜值主题（包含在 Supportpack 中），同时支持在文件夹下拉菜单中更方便地自定义颜色。

🚀 核心功能

🤖 AI AGENT & WORKSPACE

在输入框中输入 ">" 即可唤起 Agent。用日常语言描述你的需求，它会尽力帮你执行。全新的 Workspace Agent 支持直接拖拽文档（Word, Excel, PDF, 代码文件等），让 AI 帮你分析或编辑，并严格保护你的原有排版格式。同时支持整理对话、查询数据、多轮对话及自定义技能。无论侧边栏是否开启，Agent Dock 随时待命。

📂 侧边栏与整理

📂 文件夹与自定义颜色
创建多级文件夹来分类对话，通过拖拽即可整理。支持自定义文件夹和标签的颜色，一目了然。

🔍 搜索与过滤
全文检索所有历史消息。支持按标题、标签、类型等多条件组合筛选，精准定位。可限定"在当前会话中搜索"。

🏷️ 智能标签
为对话添加自定义标签，直接在对话标题处展现，支持实时过滤。

⭐ 收藏与置顶
将最常用的 Prompt 或重要对话置顶，随时高效调用。

📊 时间轴视图
通过"今天"、"昨天"、"上周"的时间轴视图回顾你的工作轨迹。

🗑️ 批量删除
批量删除对话时同步修改 Google 端数据，彻底告别"幽灵对话"。

📥 对话导出
将单个对话导出为 Markdown、纯文本或 JSON 格式，方便分享或存档。批量导出需要 Powerpack。

✂️ Snippets 精华摘录
从 AI 回复中提取精华内容，保存到专属 Snippet 库，支持文件夹管理。

👀 对话大纲
打开大纲视图，一览长对话的结构脉络。

📝 对话备注与富提示
为对话添加自定义描述；悬停即可查看创建日期、标签和备注。

💾 自动本地备份
插件数据定时自动备份，支持手动快照和回滚到之前状态。

🔒 隐私优先承诺

• 完全本地化：我们使用浏览器内置的 SQLite 数据库存储你的文件夹结构。
• 无云端同步：你的文件夹、标签和备注不会发送到我们的服务器。
• 无数据训练：我们绝不会使用你的对话内容来训练 AI 模型。
• Agent 本地运行：AI Agent 使用你自己的 Gemini 会话，不要 API key，不消耗额外 token，数据不出你的机器。

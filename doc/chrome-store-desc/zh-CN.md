Gemini & AI Studio 一站式对话管理工具：文件夹整理、全文搜索、对话导出、提示词库、Google Drive 云同步、主题美化、AI Agent。
在一个插件中轻松管理 AI 对话的收藏、归档、搜索和备份。需要的时候，也可以让 AI 助手帮你分担一些整理工作。

BETTER SIDEBAR FOR GEMINI & AI STUDIO 希望能成为你顺手的助手。我们努力把原本简单的对话列表变成一个更有条理的知识库，让你不用一直往下翻，也能找到需要的内容。

大部分功能都是免费的。少数需要付费的功能会标注（Support Pack）或（Power Pack）。Power Pack 包含 Support Pack 的全部内容。

---

📂 整理你的对话

📂 文件夹与自定义颜色
在「库」中创建多级文件夹，拖拽即可归类对话。文件夹和标签都可以设置颜色，一眼就能分清。

🏷️ 标签
为对话添加标签，标签会直接显示在对话标题处。点击标签即可查看带有它的所有对话，还能在里面切换标签、搜索、随手添加或移除标签。

⭐ 收藏与置顶
把最常用的对话或 Prompt 置顶，随时取用。

📊 时间轴视图
按「今天」「昨天」「上周」分组，回顾你的对话轨迹。

📝 对话备注与悬停提示
为对话添加描述；悬停即可查看创建日期、标签和备注。

🗑️ 批量删除
一次选中多条对话，直接从你的 Google 账号中删除，而不只是从列表里隐藏。告别「幽灵对话」。

---

🔍 快速找到任何内容

⌨️ Cmd+K 快捷指令面板
按下 Cmd+K (Mac) 或 Ctrl+K (Windows) 唤出居中的搜索面板，可搜索对话标题、描述、完整消息正文和插件功能，全程键盘操作。支持多条件组合筛选，也可以只在当前对话中搜索。

🔄 后台消息同步
历史消息会在后台安静地同步，没点开过的对话、在其他设备上发起的对话，也都能被全文搜索到。需手动开启，同步节奏平缓，附带同步状态总览，也支持单条对话手动同步。

👀 对话大纲
打开大纲视图，一眼看清长对话的结构。

---

📝 提示词、摘录与导出

📝 提示词库
建立你自己的可复用 Prompt 库。支持选项型变量、提示词组合，以及系统提示词导入。在 Gemini 和 AI Studio 中输入 "/" 即可插入。

✂️ Snippets 精华摘录
从任意 AI 回复中摘录精华，保存到 Snippet 库，支持文件夹管理。

📤 对话导出
单条或批量导出为 Markdown、纯文本或 JSON，方便整理文档或备份。

🔗 导出到 Notion & Obsidian（Power Pack）
把对话和 Snippet 发送到 Notion 或 Obsidian，尽量保留原有格式，也支持批量导出。

💎 GEM 与 NOTEBOOK

💎 Gem 管理
在侧边栏中浏览、筛选、创建 Gem，并直接发起 Gem 对话。

📓 Notebook 集成
在侧边栏中浏览、整理和管理你的 Gemini Notebook。

⚡ Gemini Spark
如果你的 Google 账号有 Spark，它会作为一个原生 tab 出现，无需任何配置。

🤖 AI AGENT

输入 ">" 选择一个 Agent，然后用日常语言描述你想做的事。每个 Agent 都有一排快速开始按钮，告诉你可以问它什么。Agent 通过你自己的 Gemini 会话运行，不需要 API key，也没有额外费用。

🧭 BetterSidebar Agent
• 查找和查询你的对话、文件夹和标签（免费）
• 帮你动手整理：新建文件夹、移动对话、批量打标签、重命名和清理（Power Pack）
• 在新对话中继续：对话太长时，它会写一份交接总结，并打开一个新对话，把总结放在输入框里。在你按下回车之前，不会发送任何内容。
• 主题工坊：描述你想要的感觉，它会生成并应用一套主题，你可以继续通过对话微调（应用自定义主题：Support Pack）
• 通过 Agent Dock，侧边栏关闭时也能使用

📁 Workspace Agent
拖入文档（Word、Excel、PDF、代码文件等），让 AI 帮你分析或编辑，同时保留原有排版。免费版支持 1 个工作区、最多 5 个文件；更多工作区和文件需要 Power Pack。

🌐 Browser Agent（实验性）
跨所有窗口去重标签页、把相关标签页分组、清理杂乱的书签文件夹。整理标签页、关闭标签页、整理书签、删除书签各有独立的权限开关。每次执行前都会自动创建快照，支持一键回退。读取标签页和书签免费；实际应用更改需要 Power Pack。

🔒 隐私优先

我们非常重视你的隐私。

• 完全本地：你的文件夹、标签、备注和 Prompt 都存储在浏览器内置的 SQLite 数据库中。
• 没有存放你数据的后端：插件没有任何存储或接收你对话、整理数据的服务器。Google Drive 同步只会写入你自己的 Drive。我们唯一处理的请求，是你激活付费包时的许可证校验。
• 不用于训练：我们绝不会读取你的对话来训练 AI 模型。
• Agent 使用你自己的会话：AI Agent 通过你现有的 Google 会话与 Gemini 交互，和你自己使用 Gemini 的方式一样，不会把任何内容发给我们或其他第三方。

为什么需要这些权限？

我们需要访问 aistudio.google.com 和 gemini.google.com，用于加载增强侧边栏、读取对话标题以便整理。标签页和书签权限是可选的：只有在你启用 Browser Agent 时才会申请，并且只在你打开的开关范围内使用。我们不会读取你的浏览历史。

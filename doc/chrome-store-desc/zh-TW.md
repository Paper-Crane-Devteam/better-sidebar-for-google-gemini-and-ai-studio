Gemini & AI Studio 一站式對話管理工具：資料夾整理、全文搜尋、對話匯出、AI Agent 自動化、提示詞庫、Google Drive 雲端同步、主題美化。
在一個套件中輕鬆管理 AI 對話的收藏、歸檔、搜尋和備份。現在，你還可以嘗試讓 AI 助手為你分擔一些整理工作。

BETTER SIDEBAR FOR GEMINI & AI STUDIO 希望能成為你得力的助手，為你提升工作效率。我們努力將原本簡單的列表結構轉化為一個更有條理的知識庫，讓你的 AI 工作流更加順暢。

🔥 最新更新 (v2.10.0)

💼 Workspace Agent (讓 AI 直接幫你編輯檔案)：
• 這是一個非常關鍵的功能！輸入 ">" 喚起 Workspace Agent，將檔案（支援 Word, Excel, PDF, 字幕, 純文字, Markdown 及各類程式碼檔案等）拖入工作區，Agent 即可直接幫你查看、分析甚至編輯它們。
• 最大的亮點是「絕不弄亂排版」。它基於修訂和精確替換（而非暴力覆寫），讓你原有的表格公式、Word 樣式、字幕時間軸等均得到完美保護。
• 目前由於瀏覽器限制，需先上傳檔案且暫不支援直接預覽。此功能正處於 Beta 階段，解鎖 Powerpack 可享無限容量。

✨ 體驗最佳化：
• 緊湊模式：可選擇完全隱藏側邊欄圖示欄，瞬間獲得極致清爽的沉浸式工作介面。
• 臨時對話擴展：AI Studio 新增模擬「臨時對話」體驗，隨意測試不留痕跡（不會記錄到檔案樹）。同時修復了 Gemini 臨時對話偶爾在資料夾亂建項目的問題。
• 快捷操作提升：New chat 按鈕現支援滑鼠中鍵快速在新分頁打開；新增 F2 快捷重新命名和 Delete 快捷刪除，順應你的肌肉記憶。
• 資料夾秒搜：資料夾選擇彈窗新增搜尋功能，檔案再多也能一秒定位。
• 介面與互動：修復了分支對話時智慧捲軸順序混亂的問題；AI Studio 主題側邊欄背景顏色已修正；側邊欄新增帳號頭像顯示，多帳號切換一目瞭然。
• 新增 6 款高顏值主題（包含在 Supportpack 中），同時支援在資料夾下拉選單中更方便地自訂顏色。

🚀 核心功能

🤖 AI AGENT & WORKSPACE

在輸入框中輸入 ">" 即可喚起 Agent。用日常語言描述你的需求，它會盡力幫你執行。全新的 Workspace Agent 支援直接拖曳文件（Word, Excel, PDF, 程式碼檔案等），讓 AI 幫你分析或編輯，並嚴格保護你的原有排版格式。同時支援整理對話、查詢資料、多輪對話及自訂技能。無論側邊欄是否開啟，Agent Dock 隨時待命。

📂 側邊欄與整理

📂 資料夾與自訂顏色
建立多層資料夾分類對話，拖拽即可整理。支援自訂資料夾和標籤顏色。

🔍 搜尋與篩選
全文檢索所有歷史訊息。支援按標題、標籤、類型等多條件組合篩選。可限定「在目前對話中搜尋」。

🏷️ 智慧標籤
為對話加上自訂標籤，直接在標題處顯示，支援即時篩選。

⭐ 收藏與置頂
將最常用的 Prompt 或重要對話置頂，隨時快速存取。

📊 時間軸檢視
透過「今天」、「昨天」、「上週」分組瀏覽你的工作軌跡。

🗑️ 批次刪除
批次刪除對話時同步修改 Google 端資料，徹底告別幽靈對話。

📥 對話匯出
將單一對話匯出為 Markdown、純文字或 JSON。批次匯出需 Powerpack。

✂️ Snippets 精華摘錄
從 AI 回覆中擷取精華，存入專屬 Snippet 庫，支援資料夾管理。

👀 對話大綱
開啟大綱檢視，一覽長對話的結構脈絡。

📝 對話備註與富提示
為對話加上說明；懸停即可查看建立日期、標籤和備註。

💾 自動本機備份
套件資料定時自動備份，支援手動快照和回滾到之前狀態。

🔒 隱私優先承諾

• 完全本機化：使用瀏覽器內建 SQLite 資料庫儲存你的資料夾結構。
• 無雲端同步：你的資料夾、標籤和備註不會傳送到我們的伺服器。
• 無資料訓練：絕不使用你的對話內容訓練 AI 模型。
• Agent 本機執行：AI Agent 使用你自己的 Gemini 工作階段，不需 API key，不消耗額外 token，資料不離開你的電腦。

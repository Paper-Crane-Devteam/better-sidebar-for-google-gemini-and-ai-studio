Gemini & AI Studio 一站式對話管理工具：資料夾整理、全文搜尋、對話匯出、提示詞庫、Google Drive 雲端同步、主題美化、AI Agent。
在一個套件中輕鬆管理 AI 對話的收藏、歸檔、搜尋和備份。需要的時候，也可以讓 AI 助手幫你分擔一些整理工作。

BETTER SIDEBAR FOR GEMINI & AI STUDIO 希望能成為你順手的助手。我們努力把原本簡單的對話列表變成一個更有條理的知識庫，讓你不用一直往下捲，也能找到需要的內容。

大部分功能都是免費的。少數需要付費的功能會標註（Support Pack）或（Power Pack）。Power Pack 包含 Support Pack 的全部內容。

📂 整理你的對話

📂 資料夾與自訂顏色
在「資料庫」中建立多層資料夾，拖曳即可歸類對話。資料夾和標籤都可以設定顏色，一眼就能分清。

🏷️ 標籤
為對話加上標籤，標籤會直接顯示在對話標題處。點擊標籤即可查看帶有它的所有對話，還能在裡面切換標籤、搜尋、隨手新增或移除標籤。

⭐ 收藏與置頂
把最常用的對話或 Prompt 置頂，隨時取用。

📊 時間軸檢視
依「今天」「昨天」「上週」分組，回顧你的對話軌跡。

📝 對話備註與懸停提示
為對話加上描述；懸停即可查看建立日期、標籤和備註。

🗑️ 批次刪除
一次選取多則對話，直接從你的 Google 帳號中刪除，而不只是從列表裡隱藏。告別「幽靈對話」。

🔍 快速找到任何內容

⌨️ Cmd+K 快捷指令面板
按下 Cmd+K (Mac) 或 Ctrl+K (Windows) 喚出置中的搜尋面板，可搜尋對話標題、描述、完整訊息內文和套件功能，全程鍵盤操作。支援多條件組合篩選，也可以只在目前對話中搜尋。

🔄 背景訊息同步
歷史訊息會在背景安靜地同步，沒點開過的對話、在其他裝置上發起的對話，也都能被全文搜尋到。需手動開啟，同步節奏平緩，附帶同步狀態總覽，也支援單則對話手動同步。

👀 對話大綱
開啟大綱檢視，一眼看清長對話的結構。

---

📝 提示詞、摘錄與匯出

📝 提示詞庫
建立你自己的可重複使用 Prompt 庫。支援選項型變數、提示詞組合，以及系統提示詞匯入。在 Gemini 和 AI Studio 中輸入 "/" 即可插入。

✂️ Snippets 精華摘錄
從任意 AI 回覆中摘錄精華，儲存到 Snippet 庫，支援資料夾管理。

📤 對話匯出
單則或批次匯出為 Markdown、純文字或 JSON，方便整理文件或備份。

🔗 匯出到 Notion & Obsidian（Power Pack）
把對話和 Snippet 傳送到 Notion 或 Obsidian，盡量保留原有格式，也支援批次匯出。

🤖 AI AGENT

輸入 ">" 選擇一個 Agent，然後用日常語言描述你想做的事。每個 Agent 都有一排快速開始按鈕，告訴你可以問它什麼。Agent 透過你自己的 Gemini 工作階段執行，不需要 API key，也沒有額外費用。

🧭 BetterSidebar Agent
• 查找和查詢你的對話、資料夾和標籤（免費）
• 幫你動手整理：新增資料夾、移動對話、批次加標籤、重新命名和清理（Power Pack）
• 在新對話中繼續：對話太長時，它會寫一份交接摘要，並開啟一個新對話，把摘要放在輸入框裡。在你按下 Enter 之前，不會送出任何內容。
• 主題工坊：描述你想要的感覺，它會產生並套用一套主題，你可以繼續透過對話微調（套用自訂主題：Support Pack）
• 透過 Agent Dock，側邊欄關閉時也能使用

📁 Workspace Agent
拖入文件（Word、Excel、PDF、程式碼檔案等），讓 AI 幫你分析或編輯，同時保留原有排版。免費版支援 1 個工作區、最多 5 個檔案；更多工作區和檔案需要 Power Pack。

🌐 Browser Agent（實驗性）
跨所有視窗去除重複分頁、把相關分頁分組、清理雜亂的書籤資料夾。整理分頁、關閉分頁、整理書籤、刪除書籤各有獨立的權限開關。每次執行前都會自動建立快照，支援一鍵復原。讀取分頁和書籤免費；實際套用變更需要 Power Pack。

🕹 Web Agent（實驗性、Power Pack、Chrome）
把網頁交給 AI，讓它幫你填寫表單、依步驟點擊，或整理出一張表格。在 Gemini 中輸入 ">Web Agent"，或在任意網頁上按右鍵選擇「讓 Web Agent 操作此頁面」。任務在 Chrome 側邊面板中執行，每一次點擊、每一次輸入、每一段腳本在執行前都需要你核准。操作網頁需要安裝免費的配套擴充功能「Better Sidebar Web Agent Connector」，由它持有 Chrome 的頁面偵錯權限，Better Sidebar 本身不需要申請。隨時點擊 Chrome 偵錯提示列上的「取消」即可停止。

🔒 隱私優先

我們非常重視你的隱私。

• 完全本機：你的資料夾、標籤、備註和 Prompt 都儲存在瀏覽器內建的 SQLite 資料庫中。
• 沒有存放你資料的後端：套件沒有任何儲存或接收你對話、整理資料的伺服器。Google Drive 同步只會寫入你自己的 Drive。我們唯一處理的請求，是你啟用付費包時的授權碼驗證。
• 不用於訓練：我們絕不會讀取你的對話來訓練 AI 模型。
• Agent 使用你自己的工作階段：AI Agent 透過你現有的 Google 工作階段與 Gemini 互動，和你自己使用 Gemini 的方式一樣，不會把任何內容傳給我們或其他第三方。

為什麼需要這些權限？

我們需要存取 aistudio.google.com 和 gemini.google.com，用於載入增強側邊欄、讀取對話標題以便整理。分頁和書籤權限是選用的：只有在你啟用 Browser Agent 時才會申請，並且只在你開啟的開關範圍內使用。側邊面板、右鍵選單和網路規則權限僅供 Web Agent 使用：用於在 Chrome 側邊面板中顯示 Gemini，以及新增它唯一的一個選單項目。我們不會讀取你的瀏覽紀錄。

Универсальный органайзер чатов, менеджер промптов и набор инструментов для Google Gemini и AI Studio.
Организуйте разговоры по папкам, ищите по всем сообщениям, экспортируйте чаты, синхронизируйте с Google Drive — и теперь позвольте AI-агенту управлять вашими данными.

BETTER SIDEBAR FOR GEMINI & AI STUDIO — максимальный ускоритель рабочего процесса для разработчиков, промпт-инженеров и продвинутых пользователей ИИ.

Мы превращаем стандартный интерфейс в мощную организованную базу знаний. Хватит бесконечно листать историю — начните работать эффективно.

🔥 НОВОЕ (v2.11.0)

⌨️ Палитра команд Cmd+K (В стиле Raycast):
• Нажмите Cmd+K (Mac) или Ctrl+K (Windows) для мгновенного вызова панели быстрых действий. Поиск по заголовкам, тексту сообщений и запуск функций расширения прямо с клавиатуры.

🔄 Тихая синхронизация сообщений в фоне (Полноценный сквозной поиск):
• Больше ни один результат не потеряется! История сообщений теперь тихо индексируется в фоновом режиме без необходимости открывать каждый чат вручную. С окном статуса синхронизации и ручным запуском для отдельных диалогов (по умолчанию отключено для защиты от лимитов).

🤖 Browser Agent (ИИ-помощник для браузера, Экспериментально):
• ИИ берет на себя порядок в браузере: удаление дубликатов вкладок, умная группировка по темам и генеральная уборка закладок. Автоматические снимки состояния и откат изменений в один клик.

🎨 Создание тем на лету с BetterSidebar Agent:
• Забудьте о копировании промптов и файлов JSON. Опишите цветовую гамму в чате, и агент сразу же сгенерирует и применит тему с возможностью точечной подстройки в диалоге.

🧩 Настройка и сортировка панели иконок:
• Скрывайте вкладки, которыми не пользуетесь каждый день, и меняйте порядок значков простым перетаскиванием (drag-and-drop).

🛠️ Исправления и полировка:
• AI Studio UI: Восстановлено сворачивание сайдбара после недавних изменений разметки со стороны Google.
• Маршрутизация папок: Исправлен баг, из-за которого новые чаты ошибочно попадали в «Inbox» при выбранной другой папке.
• Контраст темы Retro: Снижена избыточная насыщенность в теме Retro Terminal для комфортного чтения без утомления глаз.

🚀 ОСНОВНЫЕ ФУНКЦИИ

🤖 AI AGENT & WORKSPACE

Введите «>» для вызова Agent. Опишите задачи, и он поможет их выполнить.
• Workspace Agent: Перетаскивайте документы (Word, Excel, PDF, код и т.д.) и редактируйте их силами ИИ с сохранением верстки.
• Browser Agent (Новое): Наведите порядок во вкладках (удаление дубликатов, группировка) и закладках с автобэкапом и откатом в один клик.
• BetterSidebar Agent: Создавайте и применяйте собственные темы на лету, сортируйте чаты и запрашивайте данные. Доступен даже при закрытом сайдбаре через Agent Dock.

🏷️ Умные Теги
Пользовательские теги, видимые в заголовке чата. Мгновенная фильтрация.

🗑️ Пакетное Удаление

📥 Экспорт Разговоров

✂️ Сниппеты

🔒 КОНФИДЕНЦИАЛЬНОСТЬ ПРЕЖДЕ ВСЕГО

• 100% локально: встроенная SQLite база данных в браузере.
• Без отправки на наши серверы: папки, теги и заметки НЕ уходят к нам.
• Без обучения: мы не читаем ваши разговоры для тренировки ИИ.
• Agent работает локально: используется ваша собственная сессия Gemini. Без API-ключей, без лишних токенов, данные не покидают машину.

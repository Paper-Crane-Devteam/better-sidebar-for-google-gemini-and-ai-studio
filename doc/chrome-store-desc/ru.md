Универсальный органайзер чатов, менеджер промптов и набор инструментов для Google Gemini и AI Studio.
Организуйте разговоры по папкам, ищите по всем сообщениям, экспортируйте чаты, синхронизируйте с Google Drive — и теперь позвольте AI-агенту управлять вашими данными.

BETTER SIDEBAR FOR GEMINI & AI STUDIO — максимальный ускоритель рабочего процесса для разработчиков, промпт-инженеров и продвинутых пользователей ИИ.

Мы превращаем стандартный интерфейс в мощную организованную базу знаний. Хватит бесконечно листать историю — начните работать эффективно.

🔥 НОВОЕ (v2.10.0)

💼 Workspace Agent (Пусть ИИ редактирует файлы за вас):
• Долгожданная функция здесь! Введите «>» для вызова Workspace Agent, перетащите файлы (Word, Excel, PDF, субтитры, Markdown, код) и позвольте ИИ проанализировать и отредактировать их.
• Самое главное? Он строго сохраняет ваше форматирование. Используя режим правок и точечные замены вместо грубой перезаписи, ваши формулы Excel, стили Word и таймкоды субтитров остаются нетронутыми.
• Сейчас в бета-версии. Powerpack открывает безлимитный доступ.

✨ Улучшения удобства:
• Компактный режим: Полностью скройте боковую панель иконок для максимально чистого интерфейса без отвлекающих факторов.
• Временные чаты для AI Studio: Имитация временного чата, не оставляющая следов. Также исправлен баг, из-за которого временные чаты Gemini создавали фантомные записи.
• Быстрые действия: Клик колесиком мыши по кнопке «New Chat» открывает его в новой вкладке. Добавлены шорткаты: F2 для переименования, Delete для удаления.
• Поиск по папкам: Добавлена строка поиска в окно выбора папки.
• Улучшения UI: Исправлен порядок smart scrollbar при ветвлении чатов, исправлен фон боковой панели в теме AI Studio, добавлено отображение аватара аккаунта для удобного переключения.
• Новые темы: 6 новых великолепных тем (в Supportpack) и более удобный выбор кастомного цвета прямо в меню папки.

🚀 ОСНОВНЫЕ ФУНКЦИИ

🤖 AI AGENT & WORKSPACE

Введите «>» для вызова Agent. Опишите задачи, и он поможет их выполнить. С новым Workspace Agent вы можете перетаскивать документы (Word, Excel, PDF, код и т.д.) и позволить ИИ анализировать или редактировать их, строго сохраняя исходное форматирование. Также поддерживает автосортировку чатов, запросы к данным, кастомные навыки и многораундовый контекст. Работает через Agent Dock даже при закрытом сайдбаре.

🔒 КОНФИДЕНЦИАЛЬНОСТЬ ПРЕЖДЕ ВСЕГО

• 100% локально: встроенная SQLite база данных в браузере.
• Без отправки на наши серверы: папки, теги и заметки НЕ уходят к нам.
• Без обучения: мы не читаем ваши разговоры для тренировки ИИ.
• Agent работает локально: используется ваша собственная сессия Gemini. Без API-ключей, без лишних токенов, данные не покидают машину.

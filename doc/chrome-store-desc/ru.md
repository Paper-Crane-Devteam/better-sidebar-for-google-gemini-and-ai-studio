Универсальный органайзер чатов, менеджер промптов и набор инструментов для Google Gemini и AI Studio.
Организуйте разговоры по папкам, ищите по всем сообщениям, экспортируйте чаты, синхронизируйте с Google Drive, а при желании поручите AI-агенту помочь с управлением данными.

BETTER SIDEBAR FOR GEMINI & AI STUDIO создан, чтобы упростить повседневную работу разработчиков, промпт-инженеров и активных пользователей ИИ. Мы стараемся превратить стандартный интерфейс в более упорядоченную базу знаний, чтобы нужное находилось без бесконечной прокрутки.

Большинство функций бесплатны. Немногие платные отмечены как (Support Pack) или (Power Pack). Power Pack включает всё из Support Pack.

📂 УПОРЯДОЧЬТЕ ЧАТЫ

📂 Папки и цвета
Перетаскивайте чаты во вложенные папки на вкладке «Библиотека». Назначайте цвета папкам и тегам, чтобы различать их с первого взгляда.

🏷️ Теги
Отмечайте разговоры тегами — они видны прямо в заголовке чата. Нажмите на тег, чтобы открыть все чаты с ним, а там переключайтесь между тегами, ищите внутри или добавляйте и снимайте теги на месте.

⭐ Избранное и закрепление
Закрепляйте самые важные чаты и промпты сверху для быстрого доступа.

📊 Хронология
Чаты сгруппированы по «Сегодня», «Вчера» и «На прошлой неделе».

📝 Заметки к чатам и подробные подсказки
Добавляйте описания к чатам; наведите курсор, чтобы увидеть дату создания, теги и заметки.

🗑️ Массовое удаление
Выберите несколько разговоров и удалите их из аккаунта Google за один раз, а не просто скройте из списка. Никаких «призрачных» чатов.

🔍 НАХОДИТЕ ЧТО УГОДНО

⌨️ Командная палитра Cmd+K
Нажмите Cmd+K (Mac) или Ctrl+K (Windows), чтобы открыть панель поиска по центру экрана. Ищите по названиям, описаниям, полному тексту сообщений и инструментам расширения — всё с клавиатуры. Комбинируйте фильтры или ищите только в текущем разговоре.

🔄 Фоновая синхронизация сообщений
История сообщений тихо синхронизируется в фоне, поэтому полнотекстовый поиск охватывает и чаты, которые вы ещё не открывали, включая начатые на других устройствах. Включается вручную, работает в щадящем темпе, есть обзор состояния синхронизации и кнопка ручной синхронизации отдельного чата.

👀 Структура разговора
Откройте режим «Структура», чтобы сразу увидеть строение длинного разговора.

🤖 AI-АГЕНТЫ

Введите «>», чтобы выбрать агента, и опишите задачу обычными словами. У каждого агента есть ряд кнопок быстрого старта, подсказывающих, о чём его можно попросить. Агенты работают через вашу собственную сессию Gemini — без API-ключей и дополнительных затрат.

🧭 BetterSidebar Agent
• Поиск и запросы по чатам, папкам и тегам (бесплатно)
• Наводит порядок за вас: создаёт папки, перемещает чаты, массово расставляет теги, переименовывает и прибирает (Power Pack)
• Продолжить в новом чате: когда чат становится слишком длинным, агент пишет сводку для передачи контекста и открывает новый чат, где эта сводка уже ждёт в поле ввода. Ничего не отправляется, пока вы не нажмёте Enter.
• Мастерская тем: опишите нужное настроение — агент создаст и применит тему, которую можно дальше дорабатывать в диалоге (применение пользовательских тем: Support Pack)
• Работает даже при закрытой боковой панели — через Agent Dock

📁 Workspace Agent
Перетащите документы (Word, Excel, PDF, файлы кода и другие), и ИИ проанализирует или отредактирует их с сохранением исходного форматирования. Бесплатно — 1 рабочее пространство и до 5 файлов; больше пространств и файлов — с Power Pack.

🌐 Browser Agent
Удаляет дубликаты вкладок во всех окнах, группирует связанные вкладки и наводит порядок в запутанных папках закладок. Отдельные переключатели разрешений: упорядочивание вкладок, закрытие вкладок, упорядочивание закладок и удаление закладок. Перед каждым запуском создаётся снимок с откатом в один клик. Чтение вкладок и закладок бесплатно; применение изменений требует Power Pack.

🕹 Web Agent (экспериментально, Power Pack, Chrome)
Передайте веб-страницу ИИ, и он заполнит формы, прокликает нужные шаги или соберёт для вас таблицу. Введите «>Web Agent» в Gemini или щёлкните правой кнопкой мыши по любой странице и выберите «Поручить Web Agent работу с этой страницей». Задача выполняется в боковой панели Chrome, а вы подтверждаете каждый клик, каждый ввод текста и каждый скрипт до их выполнения. Для управления страницами нужно бесплатное расширение-компаньон «Better Sidebar Web Agent Connector»: разрешение Chrome на отладку страниц есть у него, поэтому самому Better Sidebar оно не требуется. Чтобы остановить работу, в любой момент нажмите «Отмена» на панели отладки Chrome.

🔒 КОНФИДЕНЦИАЛЬНОСТЬ ПРЕЖДЕ ВСЕГО

Мы серьёзно относимся к вашей конфиденциальности.

• 100 % локально: ваши папки, теги, заметки и промпты хранятся во встроенной базе SQLite прямо в браузере.
• Нет бэкенда для ваших данных: у расширения нет сервера, который хранит или получает ваши чаты и данные об их организации. Синхронизация с Google Drive идёт в ваш собственный Drive. Единственный запрос, который мы обрабатываем, — проверка лицензионного ключа при активации пакета.
• Без обучения: мы никогда не читаем ваши разговоры для обучения моделей ИИ.
• Агенты используют вашу сессию: AI-агенты общаются с Gemini через вашу текущую сессию Google — так же, как вы сами. Ничего не отправляется ни нам, ни другим третьим лицам.

ЗАЧЕМ РАСШИРЕНИЮ РАЗРЕШЕНИЯ?

Доступ к aistudio.google.com и gemini.google.com нужен, чтобы добавить улучшенную боковую панель и читать названия чатов для их организации. Доступ к вкладкам и закладкам необязателен: он запрашивается только при включении Browser Agent и используется только в рамках включённых вами переключателей. Разрешения на боковую панель, контекстное меню и сетевые правила используются только Web Agent: чтобы показывать Gemini в боковой панели Chrome и добавить его единственный пункт меню. Мы не читаем историю браузера.

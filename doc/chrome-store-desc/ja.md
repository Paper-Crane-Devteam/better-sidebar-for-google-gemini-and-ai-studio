Google Gemini と AI Studio のためのオールインワン会話管理ツール：フォルダ整理、全文検索、エクスポート、AIエージェント自動化、プロンプトライブラリ、Google Drive同期、テーマカスタマイズ。
会話をフォルダに整理し、メッセージを横断検索し、チャットをエクスポートし、Google Driveに同期 — さらに AIエージェントにデータ管理を任せられます。

BETTER SIDEBAR FOR GEMINI & AI STUDIO — 開発者、プロンプトエンジニア、AIパワーユーザーのための究極のワークフローブースター。

デフォルトのインターフェースを強力で整理されたナレッジベースに変えます。延々とスクロールするのはもうやめて、効率的に作業しましょう。

🔥 最新アップデート (v2.11.0)

⌨️ Cmd+K コマンドパレット（Raycastスタイル）：
• Cmd+K（Mac）または Ctrl+K（Windows）で中央にパレットを瞬時に呼び出し。チャットタイトル、メッセージ本文、拡張機能ツールをキーボードのみで爆速操作。

🔄 バックグラウンドメッセージ同期（真のクロスデバイス全文検索）：
• 検索の取りこぼしを完全解消！過去のチャットを1つずつ開く必要なく、バックグラウンドで静かにメッセージを自動インデックス化。同期管理パネルと個別手動同期機能付き（安全なレート制限・デフォルトOFF）。

🤖 Browser Agent（ブラウザ整理係、実験的機能）：
• AIの守備範囲をブラウザへ拡張：タブの重複排除・トピック別スマートグループ化、何年も放置されたブックマークの大掃除。自動スナップショット機能でいつでもワンクリック復元可能。

🎨 BetterSidebar Agent リアルタイムテーマ生成：
• プロンプトやJSONのコピペはもう不要。欲しい色合いをチャットで伝えるだけで、Agentがテーマを生成＆即座にプレビュー適用。対話での微調整も自在。

🧩 アイコンバーの完全カスタマイズ＆並び替え：
• 左端の機能アイコンを自由に表示/非表示＆ドラッグ＆ドロップで並び替え。ミニマルで自分専用のワークスペースを構築可能。

🛠️ 体験改善とバグ修正：
• AI Studio UI修正：Google側のレイアウト変更に追従し、サイドバーの展開/折りたたみ不具合を解消。
• フォルダ振り分け修正：特定のフォルダを選択して新規作成したチャットが勝手に「Inbox」に入る問題を修正。
• Retroテーマの視認性向上：レトロ端末テーマの彩度を抑え、長時間見つめても目が疲れにくいようコントラストを最適化。

🚀 主要機能

🤖 AI AGENT & WORKSPACE

「>」を打ってAgentを呼び出す。日常の言葉でタスクを説明すると、実行を手伝ってくれます。
• Workspace Agent：ドキュメント（Word、Excel、PDF、コードなど）をドラッグ＆ドロップし、元の書式を完全に維持したままAIに分析や編集を依頼。
• Browser Agent（新機能）：重複タブの整理・グループ化、乱雑なブックマークの整理を自動スナップショット＆ワンクリック復元付きで実行。
• BetterSidebar Agent：カスタムテーマを対話で瞬時に生成・適用、チャット整理、データ照会に対応。サイドバーを閉じてもAgent Dockから利用可能。

左端のツールアイコンの表示/非表示やドラッグ＆ドロップによる並び替えに対応。

🔍 検索＆フィルター

⌨️ Cmd+K コマンドパレット＆バックグラウンド同期
Cmd+K / Ctrl+K でタイトル、説明文、ツール、そしてメッセージ本文を横断する一括検索を起動。バックグラウンド同期との連携により、複数デバイス間でも完全なオフライン全文検索を実現。複合フィルターやチャット内検索も自在。

🏷️ スマートタグ

👀 会話アウトライン

📝 チャット備考＆リッチツールチップ

🔒 プライバシーファースト

• 100%ローカル：ブラウザ内蔵SQLiteデータベースを使用。
• クラウド送信なし：フォルダ、タグ、メモは我々のサーバーに送信されません。
• トレーニング利用なし：会話内容をAIモデルのトレーニングに使用しません。
• Agentはローカル実行：あなた自身のGeminiセッションを使用。APIキー不要、追加トークン消費なし、データはマシンの外に出ません。

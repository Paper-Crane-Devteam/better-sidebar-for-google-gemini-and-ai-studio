Google Gemini と AI Studio のためのオールインワン会話管理ツール：フォルダ整理、全文検索、エクスポート、プロンプトライブラリ、Google Drive 同期、テーマカスタマイズ、AIエージェント。
会話をフォルダに整理し、メッセージを横断検索し、チャットをエクスポートし、Google Drive に同期。必要なときは AIエージェントにデータの整理を手伝ってもらうこともできます。

BETTER SIDEBAR FOR GEMINI & AI STUDIO は、開発者、プロンプトエンジニア、AI を日常的に使う方の作業を少しでも楽にしたいと考えて作りました。デフォルトの画面を整理されたナレッジベースに近づけ、延々とスクロールしなくても必要なものが見つかるようにしています。

ほとんどの機能は無料です。有料の機能には（Support Pack）または（Power Pack）と記載しています。Power Pack には Support Pack の内容がすべて含まれます。

---

📂 チャットを整理する

📂 フォルダ＆カラー
「ライブラリ」でネストしたフォルダを作り、ドラッグ＆ドロップでチャットを分類。フォルダやタグに色を付けて、ひと目で見分けられます。

🏷️ タグ
チャットにタグを付けると、チャットヘッダーに表示されます。タグをクリックすると、そのタグが付いたチャットを一覧表示。そこからタグの切り替え、タグ内の検索、タグの追加・削除もできます。

⭐ お気に入り＆ピン留め
よく使うチャットやプロンプトを上部にピン留めして、すぐに開けます。

📊 タイムラインビュー
「今日」「昨日」「先週」でグループ化して表示します。

📝 チャット備考＆ツールチップ
チャットに説明を追加。ホバーで作成日、タグ、メモを確認できます。

🗑️ 一括削除
複数の会話をまとめて選択し、一覧から隠すだけでなく Google アカウントから実際に削除します。ゴーストチャットはもう残りません。

---

🔍 何でもすぐに見つける

⌨️ Cmd+K コマンドパレット
Cmd+K（Mac）または Ctrl+K（Windows）で中央に検索パネルを表示。チャットタイトル、説明、メッセージ本文、拡張機能のツールをキーボードだけで検索できます。複数のフィルターの組み合わせや、現在の会話内だけの検索にも対応。

🔄 バックグラウンドメッセージ同期
過去のメッセージをバックグラウンドで静かに同期するので、まだ開いていないチャットや他のデバイスで始めたチャットも全文検索の対象になります。オプトイン方式で、負荷を抑えた同期ペース、同期状況の一覧、チャット単位の手動同期ボタン付き。

👀 会話アウトライン
アウトラインビューで、長い会話の構造をひと目で把握できます。

---

📝 プロンプト、Snippets＆エクスポート

📝 プロンプトライブラリ
再利用できるプロンプトのライブラリを作れます。オプション変数、プロンプトの組み合わせ、システムプロンプトのインポートに対応。Gemini と AI Studio の両方で「/」を入力して挿入できます。

✂️ Snippets
AI の回答から気になる部分を切り出し、フォルダ管理付きの Snippet ライブラリに保存します。

📤 会話エクスポート
1件でも複数件でも、Markdown、プレーンテキスト、JSON でエクスポートできます。ドキュメント作成やバックアップに。

🔗 Notion＆Obsidian へのエクスポート（Power Pack）
会話や Snippet を Notion や Obsidian に送信します。書式はできるだけそのまま保ちます。一括エクスポートにも対応。

💎 GEM＆NOTEBOOK

💎 Gem 管理
サイドバーから Gem の閲覧、絞り込み、作成、会話の開始ができます。

📓 Notebook 連携
サイドバーから Gemini の Notebook を閲覧・整理・管理できます。

⚡ Gemini Spark
Google アカウントで Spark が使える場合、設定不要でネイティブタブとして表示されます。

🎨 UIカスタマイズ

Gemini：
• サイドバー、チャット本文、入力ボックスの幅を調整
• フォーカスモード：ロゴ、免責事項、アップグレードボタンなどを非表示
• スマートスクロールバー：任意のメッセージにジャンプ。メッセージ一覧に展開も可能
• ウォーターマークなしの画像ダウンロード（Pro の HD 画像を含む）
• テーマ切り替えアニメーション

AI Studio：
• サイドバー幅の設定
• 入力ボックスの自動非表示
• 実行設定パネルの自動非表示
• 「/」コマンドでプロンプトライブラリを呼び出し

🧩 アイコンバーのカスタマイズ
左端のツールアイコンを表示/非表示にしたり、ドラッグで好きな順番に並べ替えたりできます。

🎨 テーマ（Support Pack）
丁寧に調整した 19 種類のテーマ。切り替え時はなめらかなアニメーション付きで、ライト/ダークモードは自動で判別します。どのテーマも購入前に無料でプレビューできます。

☁️ 同期、バックアップ＆アカウント

☁️ Google Drive 同期
設定とプロンプトをあなた自身の Google Drive に自動アップロードします。復元は手動のみなので、ローカルのデータが常に正となります。

💾 自動ローカルバックアップ
拡張機能のデータを定期的に自動バックアップ。手動スナップショットや、以前の状態へのロールバックもいつでも可能です。

💾 データコントロール
整理構造（SQL ダンプ）をいつでもエクスポートしてバックアップできます。

👤 マルチアカウントプロファイル
仕事用と個人用など、プロファイルを分けて作成できます。それぞれ独立したデータベースを持ちます。

🌟 マルチプラットフォーム対応
Gemini と Google AI Studio の会話を、ひとつのサイドバーでまとめて管理できます。

🎛️ 拡張機能アイコンパネル
ブラウザのツールバーアイコンをクリックすると、クイックコントロールパネルが開きます。メニューを探さずにプラットフォームや機能をオン/オフできます。

🤖 AIエージェント

「>」を入力してエージェントを選び、やりたいことを普段の言葉で伝えてください。各エージェントにはクイックスタートボタンがあり、何を頼めるかがすぐに分かります。エージェントはあなた自身の Gemini セッションで動くので、API キーも追加費用も不要です。

🧭 BetterSidebar Agent
• チャット、フォルダ、タグの検索や問い合わせ（無料）
• 整理の代行：フォルダ作成、チャットの移動、一括タグ付け、名前変更、片付け（Power Pack）
• 新しいチャットで続ける：会話が長くなったら引き継ぎ用の要約を書き、新しいチャットを開いて入力ボックスに要約を入れておきます。Enter を押すまで何も送信されません。
• テーマ工房：欲しい雰囲気を伝えるとテーマを作って適用し、会話を続けながら微調整できます（カスタムテーマの適用：Support Pack）
• Agent Dock を使えば、サイドバーを閉じていても利用できます

📁 Workspace Agent
ドキュメント（Word、Excel、PDF、コードファイルなど）をドラッグして、元の書式を保ったまま AI に分析や編集を依頼できます。無料版は 1 ワークスペース・最大 5 ファイルまで。それ以上は Power Pack が必要です。

🌐 Browser Agent（実験的機能）
すべてのウィンドウを対象に重複タブを整理し、関連するタブをグループ化し、散らかったブックマークフォルダを片付けます。タブの整理、タブを閉じる、ブックマークの整理、ブックマークの削除には、それぞれ個別の権限スイッチがあります。実行前には毎回スナップショットを取り、ワンクリックで元に戻せます。タブやブックマークの読み取りは無料、変更の適用には Power Pack が必要です。

🕹 Web Agent（実験的機能・Power Pack・Chrome）
Web ページを AI に任せて、フォーム入力、手順に沿ったクリック操作、表のとりまとめをしてもらえます。Gemini で「>Web Agent」と入力するか、任意のページを右クリックして「Web Agent にこのページを操作させる」を選びます。タスクは Chrome のサイドパネルで実行され、クリック、文字入力、スクリプトはすべて実行前にあなたが承認します。ページの操作には無料のコンパニオン拡張機能「Better Sidebar Web Agent Connector」が必要です。Chrome のページデバッガー権限はこの拡張機能が持つため、Better Sidebar 本体には不要です。Chrome のデバッグバーで「キャンセル」を押せば、いつでも停止できます。

🔒 プライバシーファースト

プライバシーを大切に考えています。

• 100% ローカル：フォルダ、タグ、メモ、プロンプトは、ブラウザ内の組み込み SQLite データベースに保存されます。
• データを保管するバックエンドなし：拡張機能には、チャットや整理データを保存・受信するサーバーがありません。Google Drive 同期の保存先はあなた自身の Drive です。開発者側で扱う通信は、パックを有効化するときのライセンスキー確認だけです。
• 学習には使いません：会話の内容を AI モデルの学習に使うことはありません。
• エージェントはあなたのセッションを使用：AI エージェントは、あなたが普段 Gemini を使うのと同じように、既存の Google セッションを通じて Gemini とやり取りします。開発者やその他の第三者に何かが送られることはありません。

なぜ権限が必要なのですか？

aistudio.google.com と gemini.google.com へのアクセスは、強化サイドバーを表示し、整理のためにチャットタイトルを読み取るためだけに使います。タブとブックマークの権限は任意で、Browser Agent を有効にしたときにだけリクエストされ、オンにしたスイッチの範囲内でのみ使われます。サイドパネル、右クリックメニュー、ネットワークルールの権限は Web Agent 専用で、Chrome のサイドパネルに Gemini を表示し、メニュー項目を 1 つ追加するためだけに使います。閲覧履歴は読み取りません。

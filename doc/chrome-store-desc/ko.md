Google Gemini 및 AI Studio를 위한 올인원 채팅 구성 도구, 프롬프트 관리자 및 생산성 도구 키트입니다.
대화를 폴더로 정리하고, 모든 메시지를 검색하고, 채팅을 내보내고, Google 드라이브에 동기화하고, 선택적으로 AI 에이전트가 데이터 관리를 돕도록 하세요.

GEMINI 및 AI STUDIO를 위한 더 나은 사이드바를 만나보세요. 개발자, 신속한 엔지니어, AI 고급 사용자가 일상적인 작업 흐름을 간소화할 수 있도록 설계되었습니다. 우리는 기본 인터페이스를 체계적인 지식 기반으로 전환하여 끝없이 스크롤하지 않고도 필요한 것을 찾을 수 있도록 하는 것을 목표로 합니다.

대부분의 기능은 무료입니다. 팩이 필요한 소수의 팩은 (지원 팩) 또는 (파워 팩)으로 표시되어 있습니다. 파워 팩에는 지원 팩의 모든 것이 포함되어 있습니다.

📂 채팅 정리

📂 폴더 및 색상
라이브러리 탭의 중첩된 폴더에 채팅을 끌어서 놓습니다. 폴더와 태그에 사용자 정의 색상을 지정하면 쉽게 알아볼 수 있습니다.

🏷️ 태그
대화에 태그를 지정하고 채팅 헤더에서 바로 태그를 확인하세요. 태그를 클릭하여 해당 태그가 포함된 모든 채팅을 연 다음 태그를 전환하거나, 태그 내에서 검색하거나, 즉석에서 태그를 추가 및 제거하세요.

⭐ 즐겨찾기 및 고정
빠른 액세스를 위해 가장 중요한 채팅이나 메시지를 상단에 고정하세요.

📊 타임라인 보기
"오늘", "어제", "지난 주"별로 그룹화된 채팅을 확인하세요.

📝 채팅 발언 및 풍부한 도구 설명
채팅에 설명을 추가합니다. 생성 날짜, 태그, 메모를 보려면 마우스를 가져가세요.

🗑️ 일괄 삭제
여러 개의 대화를 선택하고 목록에서 숨기는 것이 아니라 한 번에 Google 계정에서 삭제하세요. 더 이상 유령 채팅이 없습니다.

🔍 무엇이든 찾아보세요

⌨️ Cmd+K 명령 팔레트
Cmd+K(Mac) 또는 Ctrl+K(Windows)를 눌러 중앙 검색 패널을 엽니다. 채팅 제목, 설명, 전체 메시지 텍스트, 확장 도구 등을 모두 키보드에서 검색하세요. 필터를 결합하거나 현재 대화 내에서 검색하세요.

🔄 배경 메시지 동기화
기록 메시지는 백그라운드에서 자동으로 동기화되므로 전체 텍스트 검색에는 다른 장치에서 시작된 채팅을 포함하여 아직 열지 않은 채팅도 포함됩니다. 부드러운 조절, 동기화 상태 개요 및 단일 채팅에 대한 수동 동기화 버튼을 사용하여 선택하세요.

🙌 대화 개요
개요 보기를 열어 긴 대화의 구조를 한 눈에 확인하세요.

📝 프롬프트, 스니펫 및 내보내기

📝 프롬프트 라이브러리
재사용 가능한 프롬프트의 개인 라이브러리를 구축하세요. 옵션 변수, 프롬프트 구성, 시스템 프롬프트 가져오기를 지원합니다. Gemini와 AI Studio 모두에 프롬프트를 삽입하려면 "/"를 입력하세요.

✂️ 스니펫
폴더 관리를 통해 AI 답변의 하이라이트를 Snippet 라이브러리에 저장하세요.

📤 대화 내보내기
문서화 또는 백업을 위해 하나 이상의 대화를 Markdown, 일반 텍스트 또는 JSON으로 한 번에 내보냅니다.

🔗 Notion & Obsidian으로 내보내기(파워팩)
대화와 스니펫을 Notion 또는 Obsidian으로 보내서 형식을 최대한 그대로 유지하세요. 배치에서도 작동합니다.

업무용 또는 개인용으로 각각 독립된 데이터베이스를 갖춘 별도의 프로필을 만듭니다.

🌟 다중 플랫폼 지원

🤖 AI 에이전트

">"를 입력하여 에이전트를 선택한 다음 원하는 내용을 일상 언어로 설명하세요. 각 에이전트에는 무엇을 물어봐야 할지 알 수 있도록 빠른 시작 버튼이 표시됩니다. 에이전트는 API 키나 추가 비용 없이 자체 Gemini 세션을 통해 실행됩니다.

🧭 BetterSidebar Agent
• 채팅, 폴더, 태그 찾기 및 쿼리(무료)
• 자동 정리: 폴더 생성, 채팅 이동, 일괄 태그 지정, 이름 변경 및 정리(파워 팩)
• 새 채팅에서 계속: 채팅이 너무 길어지면 핸드오버 요약을 작성하고 입력 상자에 요약이 대기 중인 새 채팅이 열립니다. Enter를 누를 때까지 아무 것도 전송되지 않습니다.
• 테마 워크숍: 원하는 분위기를 설명하고, 채팅을 통해 계속 다듬을 수 있는 테마를 구축 및 적용합니다. (맞춤 테마 적용: 지원 팩)
• Agent Dock을 통해 사이드바를 닫은 상태에서도 작동

📁 Workspace Agent
문서(Word, Excel, PDF, 코드 파일 등)를 드래그하면 원본 형식을 유지하면서 AI가 문서를 분석하거나 편집할 수 있습니다. 최대 5개의 파일이 포함된 작업 공간 1개는 무료입니다. Power Pack을 사용하면 더 많은 작업 공간과 파일을 사용할 수 있습니다.

🌐 Browser Agent
모든 창에서 탭을 중복 제거하고, 관련 탭을 그룹화하고, 지저분한 북마크 폴더를 정리하세요. 탭 정리, 탭 닫기, 북마크 정리, 북마크 삭제를 위한 별도의 권한 스위치. 원클릭 롤백을 통해 매 실행 전에 스냅샷이 생성됩니다. 탭과 북마크 읽기는 무료입니다. 변경 사항을 적용하려면 파워 팩이 필요합니다.

🕹 Web Agent (실험적, Power Pack, Chrome)
웹 페이지를 AI에게 맡겨 양식 작성, 단계별 클릭, 표 정리 같은 작업을 시켜 보세요. Gemini에서 ">Web Agent"를 입력하거나, 아무 페이지에서나 마우스 오른쪽 버튼을 클릭하고 "Web Agent가 이 페이지에서 작업하도록 하기"를 선택하세요. 작업은 Chrome 사이드 패널에서 실행되며, 모든 클릭, 모든 입력, 모든 스크립트는 실행 전에 사용자가 직접 승인합니다. 페이지를 조작하려면 무료 보조 확장 프로그램 "Better Sidebar Web Agent Connector"가 필요합니다. 이 확장 프로그램이 Chrome의 페이지 디버거 권한을 보유하므로 Better Sidebar 자체에는 해당 권한이 필요하지 않습니다. 언제든지 Chrome 디버깅 표시줄에서 취소를 누르면 중지됩니다.

🔒 개인정보 보호 우선

우리는 귀하의 개인정보를 중요하게 생각합니다.

• 100% 로컬: 폴더, 태그, 메모 및 프롬프트는 브라우저 내부에 내장된 SQLite 데이터베이스에 있습니다.
• 데이터 백엔드 없음: 확장 프로그램에는 채팅 또는 조직 데이터를 저장하거나 수신하는 서버가 없습니다. Google 드라이브 동기화는 내 드라이브로 이동됩니다. 우리가 처리하는 유일한 요청은 팩을 활성화할 때 라이센스 키를 확인하는 것입니다.
• 모델 학습 미사용: AI 모델 학습을 위해 대화 내용을 읽거나 사용하지 않습니다.
• 에이전트는 자체 세션을 사용: AI 에이전트는 사용자와 동일한 방식으로 기존 Google 세션을 통해 Gemini와 대화합니다. 당사나 기타 제3자에게는 아무것도 전송되지 않습니다.

확장 프로그램에 권한이 필요한 이유는 무엇입니까?

향상된 사이드바를 추가하고 조직의 채팅 제목을 읽으려면 aistudio.google.com 및 gemini.google.com에 액세스해야 합니다. 탭 및 북마크 액세스는 선택 사항입니다. 브라우저 에이전트를 활성화할 때만 요청되며, 켜는 스위치 내에서만 사용됩니다. 사이드 패널, 오른쪽 클릭 메뉴, 네트워크 규칙 권한은 Web Agent만 사용하며, Chrome 사이드 패널에 Gemini를 표시하고 메뉴 항목 하나를 추가하는 데에만 쓰입니다. 우리는 귀하의 검색 기록을 읽지 않습니다.

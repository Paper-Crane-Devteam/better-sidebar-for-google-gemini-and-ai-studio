# Browser Agent 技术方案

> 状态：已确认，开始实施。2026-09-14 根据产品决策修订。

## 1. 目标与边界

首版仅支持 Chrome。Browser Agent 在现有 Agent 入口中与 Data Agent 切换，负责标签页、标签组和收藏夹的 AI 分类、排序和语义整理。File Agent 尚未实现，不展示空入口。

不实现浏览器现场保存/恢复，不提供网页访问、正文或元数据抓取工具，不修改 document.title。标签备注仅保存在扩展本机，供扩展界面显示，不改变网页标题。

## 2. 授权和审批

新增可选 manifest 权限 tabs、tabGroups、bookmarks；沿用的 scripting/host 权限不能作为 Browser Agent 授权。产品能力默认全部关闭：

| capability | 能力 |
|---|---|
| tabs.read | 标题、URL、窗口、位置、组关系、扩展备注 |
| tabs.write | 创建、激活、移动、固定、关闭、修改扩展备注 |
| tabGroups.read | 标签组属性 |
| tabGroups.write | 分组、取消分组、更新和移动组（同时要求 tabs.read/write） |
| bookmarks.read | 收藏夹读取和搜索 |
| bookmarks.write | 创建、重命名、移动和删除（同时要求 bookmarks.read） |

权限通过用户点击申请，拒绝时保持关闭。前端只注入已授权工具，后台在准备及执行每一步重新验证实际权限和 capability。拒绝隐身对象，保护运行 Agent 的宿主标签，不允许关闭它或通过组操作搬移它。

**所有实际修改都必须批准**，包括排序、移动、激活、固定、分组、折叠、备注、收藏夹修改和撤销。极速模式、自动执行写入、批准后续操作均不能跳过 Browser Agent 的批准。纯读取不要求批准。一次批准只覆盖当前预览的固定批次，不授权未来计划。

## 3. URL 隐私

开关名为“允许 AI 读取完整 URL”，默认开启。关闭后仅返回协议和主机名，移除用户信息、路径、查询参数、fragment；特殊协议隐藏地址。标题仍然提供。URL 开关不代替浏览器读取授权。

说明文案：开启后，完整 URL 会发送到当前 AI 对话。若标题含糊且当前模型支持原生网页访问，模型可以通过链接了解页面；这是模型自身能力，插件不提供页面访问工具，也不能控制其访问。关闭后插件仅提供脱敏地址，不要求模型推断或访问完整链接。已经发送到对话的内容无法通过关闭开关收回。

本机恢复数据保留完整地址；向 AI 输出的列表、计划、执行结果和审计查询统一执行当前隐私策略。不开设任意 SQL 查询入口。标题、URL、书签名称和模型原生网页返回内容均视作不可信数据，不作为指令或授权来源。

## 4. UI 和任务隔离

Agent Tab 提供 Data Agent / Browser Agent selector、浏览器权限设置、URL 开关、本机批次记录与撤销入口。运行期间禁止切换任务类型。`>` 弹层提供 Browser Agent、整理标签页、管理标签组、整理收藏夹入口；缺少能力时引导到权限设置。

Browser Agent 仅加载浏览器 prompt、工具和 complete_task；Data Agent 无法调用浏览器工具。所有写入先生成程序校验的实际对象预览，显示数量、原值、目标和恢复限制；AI 的 change_summary 仅作为附加说明。授权已过期或对象变化时拒绝执行，重新读取并重新批准。

## 5. 工具协议

沿用 Agent 的字符串参数协议，operations 是 JSON 数组字符串；后台解析后逐项严格验证，拒绝未知操作和多余字段，批次最多 30 步。批次内操作顺序固定。新建返回真实 ID，依赖新对象的后续修改在下一次工具调用计划中使用返回 ID，并另行批准。

- browser_list_tabs：默认当前宿主窗口，可指定 window_id，分页 limit/offset。
- browser_list_tab_groups：默认当前宿主窗口，可指定 window_id。
- browser_list_bookmarks：指定 parent_id、query、limit/offset，按层读取，避免无限树输出。
- browser_update_tabs：create、activate、move、pin、close、label。
- browser_manage_tab_groups：create、update、move、ungroup。
- browser_manage_bookmarks：create、update、move、delete；删除非空目录保存完整子树。
- browser_query_changes：分页查询本机批次；batch_id 返回步骤，batch_id + step_index 按 limit/offset 分页读取对象级变更；不接受 SQL。
- browser_undo_changes：指定 batch_id，生成新的撤销预览并批准后执行。

首版不按模糊 URL 自动删除重复项。参数不同、fragment 不同的 URL 不默认等价。

## 6. 本机审计与异常恢复

使用独立 IndexedDB browser-agent-local-v1，不接入现有业务 SQLite、Drive 同步或备份；按当前 Chrome 配置文件保存，跨插件业务 profile 共用。Data Agent 的 SQL 无法修改该审计库。

批次保存 id、owner_tab_id、浏览器会话标识、创建时间、固定操作、前置快照、状态、步骤记录。每步保存 before/after、逐对象差异、逆操作、错误和 undo 状态。状态包含 prepared、applying、applied、failed、unknown、undone。

执行前必须持久化 prepared；失败则不修改。执行 API 前记录 applying，完成后读取 after 并落盘；API 或持久化结果不明确时标记 unknown，禁止自动重试。后台重启发现 applying 时标为 unknown 并保留证据。重复提交同一 plan_id 不重复执行。

串行执行浏览器批次；每一步重新检查权限、取消标记和前置快照。只要一步失败就停止后续步骤，保留已成功步骤并返回逐项结果。停止意味着不开始下一步，不承诺中断已经调用的浏览器 API，不自动回滚。

## 7. 撤销边界

撤销也是写入，必须预览和批准；仅逆序处理已明确成功的步骤，校验当前状态与 after 是否匹配，冲突直接停止，不强行覆盖。撤销自身记录结果；重复撤销不能重复执行。unknown 步骤需先人工核实，不自动撤销。

- 标签关闭只尽力重新打开 URL，不能保证恢复表单、滚动、登录中间状态或页面运行状态，预览必须说明。
- 删除目录恢复完整子树，但新对象 ID 会变化；相关逆操作需要维护新旧 ID 映射。
- 标签和组仅允许在同一浏览器会话内撤销；浏览器重启后历史可查看，但不能凭旧 ID 操作新对象。
- 原窗口、组或父目录消失时停止并提示，不能自行覆盖其他对象。
- 新建目录后来新增内容、标签导航、对象被外部移动时，视为冲突。比较与操作相关的稳定字段，避免 lastAccessed 等动态时间导致误报。

## 8. 实施顺序和验收

先实现后台权限/计划/本机审计，再接入工具与强制审批，最后接入 selector、权限 UI、批次记录和撤销。

- 首次使用能力关闭；授权失败、撤销权限后不能读写对应对象。
- 任一修改在极速模式下也必须等待批准；纯读不需要批准。
- 批准绑定实际操作；旧计划、对象变化、不同宿主提交均失败。
- 批次中断后不会重复创建/删除，失败明细可查。
- URL 关闭后列表、查询和执行返回均不包含完整地址。
- 审计留本机，不进入业务数据库备份/同步。
- 关闭恢复限制可见；撤销冲突不覆盖；跨浏览器重启不使用旧标签 ID。
- Browser Agent 不提供 SQL、正文抓取、页面访问或 HTML 标题修改。

## 9. 首版实现说明

权限设置使用扩展独立窗口，由用户点击申请 Chrome 权限。侧边栏显示权限状态、完整 URL 状态、本机记录、当前窗口标签备注；弹层未授权入口直接打开权限设置。

撤销涉及组属性或组成员关系恢复时，还需 tabGroups.write；仅撤销标签备注无需额外组写权限。备注属于本次 Chrome 会话中的单个标签，导航继续保留，关闭或重启后不自动绑定到另一个同 URL 标签。

冲突检测首版采用保守快照：标签操作检查所有普通窗口的标签及组，收藏夹操作检查收藏夹树。即使其他对象发生无关布局变化，也可能要求重新规划；不因此放宽批准约束。单个计划 10 分钟过期，最多 30 步；规划最多 2,000 个普通标签或 10,000 个书签对象。列表每页最多 100 项，预览和结果注明展示上限，完整变化保留本机。

测试入口：`node --test scripts/test-browser-agent.cjs`。覆盖强制审批、拒绝越权消息、权限撤销、计划绑定及过期上下文、冲突、取消、异常日志、URL 脱敏、审计分页、标签/组/收藏夹撤销和跨重启限制。测试使用模拟 Chrome API，不等同于真实浏览器端到端验收。
